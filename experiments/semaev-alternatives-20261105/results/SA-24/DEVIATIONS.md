# SA-24 deviations from the frozen protocol

1. **Sampler form (A2/A3).** Instead of drawing literal Jacobian elements, a monic u of degree g is drawn uniformly and weighted by w(u)=#{v: v^2 = F mod u}; the split fraction is sum(w*1[split in F]) / sum(w). This is the exact probability for a uniform element of the weight-g stratum. Checked by exhaustive enumeration of every u (g=2: p=1019, 4091; g=3: p=211, 307): sum(w)=N_g and the split sums equal the combinatorial null exactly, at every delta (results/exact_*.jsonl).
2. **Weight-g stratum.** Elements of lower weight (probability ~1/p) are not sampled. The null is the number of weight-g reduced divisors supported on F divided by N_g = #Jac minus the lower-weight counts (exact; N_2 for g=3 from the F_{p^2} point count).
3. **Point at infinity.** The odd model has one point at infinity, the Weierstrass point x=r of the even model. It is excluded from F (no Mumford representation as an affine factor). At most one point.
4. **Sample sizes.** 10^5 samples cannot reach 50 expected hits in most cells. A2 used 2e9 trials per curve, A3 1e8, 3 curves per p, 100 blocks each (block bootstrap). Cells with expected count < 50 are marked underpowered and excluded from slope fits; they are still tabulated.
5. **Slope CIs.** Pooled slope with per-delta intercepts, plus per-delta slopes; bootstrap over blocks (2,000 resamples, seed 24), since only 3 curves per p exist.
6. **Fibre control.** Null is the exact count sum_{x=1..B, x != +-r}(1+chi(g(x^2))) / (#E1-1) rather than "about"; 2e8 uniform affine points per curve.
7. **A1 sampling.** R_j generated by a 16-table random walk (steps chosen by RNG, restart every 256 steps from a fresh random aP+bQ), table entries and starts via E1 arithmetic then pullback (pullback exactness checked in Sage and C). One Jacobian addition per trial.
8. **Cantor arithmetic.** Generic polynomial Cantor (not Lange formulas). Measured rho_J = Jac add / E1 add is ~25, larger than explicit formulas would give; this scales absolute A1 cost by a constant and does not change alpha. Cross-checked vs Sage on 1250 ops (0 mismatches).
9. **Rho.** Distinguished-point rho with negation map, 32 branches, cheap branch table (small combinations), cheap restarts from the previous endpoint, doubling escape on short cycles. Not highly tuned; counts include DP and fruitless-trail overhead.
10. **A1 failures.** At small B no factor-base point can lie in the n1-subgroup (zero relations). Trial cap 20p+1e5; such runs are logged as failures and a delta is used in the optimum only if all instances solved.
11. **Primes and curves.** p = largest prime below 2^k with p = 3 mod 4. A1 curves chosen with n1 = largest prime factor of #E1, cofactor <= 16, n1 not dividing #E2.
12. **Relation count rule.** Target |F|/2+10 relations; if k is not determined then, collection continues in 10% steps. The step at which k is first determined is recorded separately as a diagnostic ("early"), not used for the verdict.
13. Bug fixes during the run (results of the buggy versions kept in results/fibre_buggy and results/a1_prefix_tablebug, not used): fibre sampler evaluated g(x) with a wrong Horner form (null was right; all fibre cells re-run); A1 walk table could contain the identity (T=O, prob ~16/n1), polluting the walk at small n1 (relations failing verification were rejected, but cost was wrong; all A1 runs k=10..20 re-run).
