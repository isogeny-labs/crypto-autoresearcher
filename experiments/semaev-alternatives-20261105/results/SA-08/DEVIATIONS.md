# Deviations (SA-08)

1. Bug found and fixed during the run. The first version of `planted.py` reduced the coefficients of f^k modulo p instead of modulo p^k, so for K >= 2 the shift polynomials p^(K-k) f^k did not vanish modulo p^K at the planted point (first_vanishes = 0 even at tiny delta). All planted_* outputs were deleted and regenerated with the corrected script; every number in REPORT.md comes from the corrected version. (`dbg.py` is the debugging script that exposed it; it imports the corrected module.)
2. The prereg asks for "the sectional capacity for the relevant adelic set". I did not compute a sectional capacity: CHFHS (arXiv:2111.14180) treat only two-variable LINEAR congruences, and the dimension-2 (Zhang/Chambert-Loir) capacity of the S_3 set was not computed. What was done instead is stated in REPORT.md (Rees-algebra identification + determinant LP + planted check). This is a change of method, not of the frozen criterion; the criterion is judged as written (a proved threshold for all auxiliary-polynomial methods: NOT obtained).
3. Planted experiments use K = 1..4 at 40/48/56 bits (24 trials per point for K <= 3, 12 for K = 4) and K = 5 at 56 bits only (8 trials per point, 5 deltas); K >= 6 (dimension >= 169) was not run for host-time reasons. The curve is y^2 = x^3 + 7 only (as in the report's calibration); no random-(a,b) control was run.
4. Success of a planted trial = a resultant of two of the six shortest reduced polynomials is nonzero and has the planted x1 as an integer root (PARI nfroots). This is stricter than "first vector vanishes".
