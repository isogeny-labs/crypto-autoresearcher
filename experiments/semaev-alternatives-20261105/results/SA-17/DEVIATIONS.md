# SA-17 deviations

1. **Interrupted and resumed by a different model.** The first executor (Sonnet tier) was cut off by an API usage limit after the box-lattice grids. A second executor (Claude Opus 5.5) resumed from the saved directory per RESUME_BRIEF.md and was itself paused once by a usage limit (container restart, about two days of wall clock between sessions; no process was left running). Finished outputs were reused, not recomputed.
2. **Stale predecessor analysis.** `results/thresholds.json`, `law.json`, `extrapolation.json` and `fig_threshold.png` were made at 05:09 from a partial v1 ("pairtest" criterion) file, before the v2 grid existed. They were moved to `results/v1/predecessor_*`. The current analysis is `results/v2_*` and `fig_threshold_v2.png` (v2 criterion); v1 is re-analysed in full as `results/v1/v1_*` for cross-checking. v1 and v2 agree within about 0.002 in delta per lattice.
3. **Success criterion of the box lattice changed between v1 and v2 (predecessor).** v1 required one *pair* of vanishing reduced rows with coprime specialisations; v2 requires the gcd of *all* vanishing rows to be 1 (isolated root), tested by specialising t and x1 at random points of GF(q^k). The integer side was checked end to end: in 39 of 39 trials where the criterion held, resultant plus root finding returned the planted (x1, x2) (`e2e_z.out`). The FF box side was not checked end to end.
4. **Field sizes.** The prereg names q = 2, 3, 5 and n = 40..96. The run used q = 3, 5, 7 (the short-Weierstrass S3 formula used here does not apply in characteristic 2) and n = 24..64 for the box lattices (host limits: 6 executors on 4 cores). The added form-lattice runs go to n = 192 (m = 2) and n = 385 (m = 3).
5. **v2 grid was incomplete when interrupted.** Missing were the q=7 n=64 (s,t)=(4,2) cell and all (6,3) cells, and the (3,1) lattice was dropped. The resumed run added the q=7 n=64 (4,2) cell and six (6,3) cells (q,n) = (3,32),(3,48),(3,64),(5,40),(7,32),(7,48). (3,1) exists in v1 only.
6. **m = 3 and m = 4.** The predecessor's m = 3 box lattice (run3.py / lat3.py, 125-dim) was never run. At toy n the per-variable bound n/50 is below one digit, so the resumed run replaced it with the exact mechanism-equivalent 5-dim form lattice for S4 (`form5.py`). m = 4 was not run.
7. **pari.sqrt stalls in F_{3^n} for n >= 96** (it hung for more than 40 s). For the m = 3 FF planting, y = r^((Q+1)/4) is used with Q = q^n ≡ 3 mod 4, so only q in {3, 7} and odd n (97 .. 385) are used. The F_p side of the two largest m = 3 cells (q=3 n=385; q=7 n=289) timed out before reaching its threshold and is reported as missing.
8. **Added mechanism experiment, not in the prereg:** `form3.py` and `form5.py` (3- and 5-dim "form" lattices in the coefficient vector of S_{m+1} viewed as a polynomial in x_R). These are diagnostics. They change no frozen criterion.
9. **Extrapolation over doublings.** The box lattices cover n = 24..64 (about 1.4 doublings) and (6,3) covers n = 32..64 (1 doubling), which is fewer than the 4 doublings in BRIEF rule 5. The form lattices cover 24..192 (3 doublings) for m = 2 and 97..385 (2 doublings) for m = 3. The verdict does not rest on an exponent fit.
