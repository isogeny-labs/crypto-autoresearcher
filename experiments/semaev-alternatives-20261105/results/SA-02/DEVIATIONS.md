# Deviations (SA-02)

1. **No certified-bound stack.** `pip install cuso` failed (no matching distribution); the Feng et al. sumset calculator, the Ehrhart check and the ePrint 2026/1027 LP are not available offline. Substitute: `reach.py`, my own Jochemsz-May-type calculator (triangular lattice, rows m'f^k p^(t-k), monomial set = t-fold sumset or t-fold convex hull of supp f, exact determinant bookkeeping, delta*(t) evaluated at t = 2..24 and Richardson-extrapolated). It is a heuristic asymptotic bound for that shift family, NOT a certificate, and it covers only the convex-shift-set family. It reproduces the report's 1/6 for S_3 in (x1,x2) (extrapolated 0.166659), which is the calibration. Part (a) therefore reads "heuristic reach", not "certified reach".
2. **The per-u constraint is a quartic, not a quadratic, in e1.** With e2 = (e1^2-u^2)/4 the term e2^2 of the conic makes g_u(e1) of degree 4 (closed form in `common.py`, verified symbolically in `check_conic.py`). The prereg text says "univariate quadratic"; the sieve uses the quartic. (It is quadratic in w = u^2 for fixed e1; see REPORT.)
3. **Per-u solver.** The sieve-by-u in (b) solves each quartic with PARI `polrootsmod` (full root finding mod p) and keeps roots with e1 <= 2B, instead of one univariate Coppersmith lattice per u. Both cost O(1) per u (so the exponent in B is the same); PARI is ~1000x cheaper per call than LLL at these sizes. The per-u Coppersmith lattice was not run separately.
4. **Batch variant (secondary).** Implemented as windows u = u0+v (conic presentation, unknowns (e1,v)) and a plain-coordinate control (x2 = c+v, unknowns (x1,v)), real LLL (fpylll, delta .99) plus resultant root extraction, level t = 2 only for the full B range. A t = 3 control run was started but exceeded its time budget (about 6-13 s per lattice at 49 dims, 64-bit p); only 3 partial rows survive in `batch_ctrl_t3_partial_raw.txt` (log overwritten by a relaunch; the rows are from the first run's output). Window size V*(B) was calibrated as the largest V (halving from B) with >= 80% recovery on 8-10 planted trials; expected time = (windows+1)/2 x mean lattice time (not wall-clock of full scans).
5. Sizes: p = nextprime(2^40), 2^52, 2^64; B = 2^6..2^15 (9 doublings) for the sieve; trials 60 for B <= 2^13, 20 above.
