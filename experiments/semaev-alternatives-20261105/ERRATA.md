# Errata to the campaign report

The campaign report (`report/semaev_alternatives_report.md`) is kept as written on 2026-11-04 so the pre-registrations can be read against it. The executors found the errors below. Each entry names the section, the corrected statement, and the executor result that established it.

1. **Arity-4 break-even cost (Sections 3.1 and 5.4).** The report says an arity-4 oracle beats rho "iff T_dec ≪ p^{1/4} at B ≈ p^{1/5}". From the same cost formula, at B = p^{1/5} the break-even oracle cost is about p^{1/10}. The p^{1/4} figure holds at the cost-optimal B ≈ (p·T_dec)^{1/5}, which is p^{1/4} when T_dec = p^{1/4}. Found by SA-15.
2. **Reach of the three-dimensional form lattice (Sections 3.2 and 6.3).** The report gives δ < 1/12 for the lattice of integer quadratics vanishing at x_R mod p. That is the unweighted figure. With columns weighted (1, B, B²) the 50% recovery crossing moves to 0.104–0.112 at 72, 96 and 128 bits, matching 1/9. Found by SA-13.
3. **Riemann–Roch presentation (Idea 15).** The report predicts that the Riemann–Roch form has "exactly one more full-size unknown than the Vieta form has small ones". The correct count is m − 1 extra full-size unknowns (the α_j) and m − 1 extra equations over the same small box. Found by SA-15.
4. **Vieta sieve (Idea 2).** For fixed u, the constraint on e_1 is a quartic, not the quadratic the report states. Found by SA-02. SA-02 also showed that requiring e_1² − 4e_2 to be a square forces e_1 + x_R to be a square, a genus-1 condition, which is why the conic view adds no leverage.
5. **Capacity theory (Idea 8).** Chinburg–Hemenway Falk–Heninger–Scherr (arXiv:2111.14180) covers linear congruences in two variables only, so it does not apply directly to S_3. SA-08 proved the 1/6 and 1/24 ceilings for the determinant (Minkowski) argument over all down-closed supports instead, and argues heuristically that capacity arguments bite only near δ = 1/2.
6. **Squarefree-collision count (Idea 10).** The "random divisor" heuristic is wrong: the squarefree part of x³ + 7 is almost always about as large as x³ + 7. Up to x = 2^22 there is exactly one collision pair (2, 212), not the predicted ~128. Found by SA-10.
7. **Idea 5 success criterion.** The frozen yield ratio did not subtract the fixed count of global (characteristic-0) relations, so SA-05 met its success clause through that floor alone. Future criteria built on global points should compare against the generic rate after subtracting the global count, or require a yield above 1/B. Found by SA-05.
