# SA-25

**Why.** X0(11) is the elliptic curve 11a1, E11: y^2 + y = x^3 - x^2 - 10x - 20. A point s of E11(F_p) that is not a cusp is a pair (E_s, C): an elliptic curve with an F_p-rational cyclic subgroup of order 11. That moduli structure gives relations among points with no decomposition step.
- Hecke: Sum over the l+1 neighbours s' of s = [a_l] s, where a_2 = -2, a_3 = -1, a_5 = 1, a_7 = -2, a_13 = 4.
- Atkin-Lehner: s + w(s) = c0, a constant, where w(E, C) = (E/C, E[11]/C).
- Every neighbour has the same trace, so relations stay inside the trace class S_t = {s : tr(E_s) = +-t}, a class-group torsor of size about h(t^2 - 4p).
- A relation closes inside S_t only when all l+1 neighbours are F_p-rational. That happens exactly when l divides the conductor [End(E_s) : Z[pi]] and s is not on the floor of the l-volcano.
- SA-09 measured norm relations on Heegner points of one field (rank/points about 0.13). This experiment measures the closed relation module inside trace classes, as a function of how composite the conductor is.

**Facts verified before freezing (`prereg/round6/verify/x011check.sage`, p = 1009 and 4001).**
- The cusp 0 is at x = 16. From q-expansions: j = (P0(x) + P1(x) y)/(x - 16)^11 with deg P0 <= 11, deg P1 <= 10, and j' = j(11 tau) = (P0'(x) + P1'(x) y)/(x - 16) with deg P0' <= 6, deg P1' <= 5. Rational coefficients up to 57 bits.
- Phi_11(j(s), j'(s)) = 0 at all 1017 and 3897 points.
- Atkin-Lehner: s + w(s) = (16, -61) for every s, where w swaps (j, j').
- T_2: 88/88 and 556/556 full rational neighbourhoods satisfy the relation. T_3: 28/28.

**Revised success line, and why.** The round-6 discussion proposed "rank/|S_t| >= 1/2" as success. Atkin-Lehner pairs alone give about |S_t|/2 independent relations, so that line is met trivially. The quantity that decides the cost is the corank c_t = |S_t| - rank. The logs in S_t are determined up to c_t unknowns. Each unknown needs one connection (a random aP + bQ landing in S_t), which costs about p/|S_t| trials.

**Protocol.**
1. Maps and checks. Rebuild j and j' from q-expansions (Sage, no Cremona database; 11a1 from coefficients). At every prime used, check Phi_11(j, j') = 0 and the Atkin-Lehner constant at all points, and verify every Hecke relation as a point identity before using it.
2. Primes. Use 20 primes, log-spaced in [10^3, 10^6] (p != 11), plus as many up to 10^7 as fit. Enumerate the non-cuspidal points with x != 16. Compute j and j'. Set t(s) = |a_p(E_j)| with PARI ellap on any curve with that j. Record points with j in {0, 1728} or ambiguous (j, j') keys separately.
3. Relations per class S_t. AL: x_s + x_w(s) = 0. T_l: Sum x_s' - a_l x_s = 0, for l in {2, 3, 5, 7, 13, 17, 19, 23}, l != p, at every s whose l+1 neighbours are all found and uniquely matched. Here x is the discrete log of the n-component, n the largest prime factor of #E11(F_p), and the Atkin-Lehner constant c0 has order 5. A prime with n = 5 or n^2 dividing #E11 is replaced by the next prime, recorded.
4. Rank over F_n of each class's relation matrix; c_t = |S_t| - rank.
5. Positive control. For p <= 2^20, compute the true logs of all points of 10 classes (baby-step giant-step on the n-component) and verify that the true log vector lies in the kernel. If the n-components are not all zero, this forces c_t >= 1.
6. Covariates per class: D = t^2 - 4p = f^2 D0, f, the primes l | f, sigma(f) = Sum over l | f, l <= 23 of 1/l, |S_t|, and the number of Cl(D0)-orbits.
7. Cost. Per class: projected total = (c_t + 1) p/|S_t| (connections) + |S_t| log2 p (class enumeration). Take the minimum over classes at each p. Fit its exponent against log2 n, and compare with rho sqrt(pi n/4) on E11[n].
8. End to end, at the three largest primes, with the class of smallest c_t:
   1. compute a kernel basis;
   2. make connections: random aP + bQ until j(aP + bQ) is in the class's j-set, by hash lookup;
   3. solve for k and verify [k]P = Q;
   4. compare wall time with matched rho on E11[n] (5 targets per prime).

**Predictions (frozen).**
- c_t/|S_t| decreases with sigma(f) but stays at or above 0.1 in every class with |S_t| >= 50.
- Atkin-Lehner alone leaves c_t about |S_t|/2.
- No class reaches bounded corank.
- The minimal projected total exponent is at least 0.5, and the measured end-to-end cost is above rho at every prime tested.

**Criteria (frozen).**
- SUCCESS: at each of the three largest primes, some class has c_t <= 10, and the end-to-end solve through that class beats matched rho, with the wall-time ratio's 95% CI excluding 1.
- KILL: for every p >= 10^5, the minimum over classes of c_t/|S_t| is at least 0.05, and the measured or projected cost exceeds rho at the two largest primes.
- INCONCLUSIVE: otherwise.
- Reported in any case: "relation source complete" if some class has c_t <= 10 at three or more primes. That would be the campaign's first relation source with no decomposition step. Even then its connection step costs about p/|S_t|, about sqrt(p), so SUCCESS is not expected to be reachable; this is stated in advance.

**Limitations known before the run.** One modular curve (X0(11)), so one target curve up to isogeny. Every elliptic curve over Q is a quotient of some X0(N), and Hecke relations push forward under the modular parametrisation, so the structure generalises, but only X0(11) is measured. Partial neighbourhoods (Galois orbits of non-rational neighbours) are excluded: each would add an unknown orbit sum per relation.

**Cost and tier.** Sonnet executor; one core; about 1 day. SageMath at `/opt/conda-sage`, PARI (ellap, polmodular, polrootsmod), numpy.
