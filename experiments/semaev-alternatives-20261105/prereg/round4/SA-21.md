# SA-21

**Why.** Rounds 1–3 measured decomposition reach. The relevant metric is total solve time for a discrete logarithm, charged end to end: factor-base setup, relation collection (every oracle call, hit or miss), linear algebra, and the descent of the target. This experiment measures that against a matched Pollard rho on the same curves, hardware and arithmetic.

**Arms.** All in one native implementation (C or Rust; the `crypto` repository's `src/cryptanalysis/prime_fast.rs` engine is a valid reference and may be ported or called), sharing the same field and group arithmetic:
1. **rho**: parallel-collision rho with the negation map and r-adding walk, single thread.
2. **IC-pair**: index calculus with the generic pair-table decomposition (m = 2), factor base x ≤ B with B tuned per size, sparse linear algebra mod N (structured Gaussian elimination or Lanczos/Wiedemann), descent by the same oracle.
3. **IC-lattice-W**: as IC-pair, but each decomposition attempt is the Weierstrass form-lattice oracle (SA-13/SA-17, 3-dim, reach ~1/9) with B = p^δ at the oracle's 50% recovery point.
4. **IC-lattice-E**: as IC-lattice-W with the twisted-Edwards y form lattice (SA-19, reach ~1/8) on an Edwards curve of the same prime-order size.
5. **IC-coppersmith-E**: as 4 with the best fixed-depth Edwards Coppersmith lattice (SA-20, t = 2 or 3), if its per-call cost allows any data point.

**Protocol.**
1. Curves: prime-order (or prime-order subgroup with small cofactor) short-Weierstrass curves and twisted-Edwards curves of matched group size N at log2 N ∈ {20, 24, 28, 32, 36, 40} (larger if an arm stays fast), 3 curves × 5 targets per size, generated deterministically and recorded.
2. Every solve is verified: the returned log k satisfies [k]G = Q.
3. Metrics per solve: wall time (single thread, `nice -n 10`, host load recorded), group additions, field multiplications, oracle calls, oracle wall time, linear-algebra time, descent time. Report each IC arm's phase breakdown.
4. Cost pricing: express every arm in group-addition equivalents (GAE). Lattice reductions and linear algebra are priced at measured wall time ÷ measured time per group addition on the same host, and also at 0, 0.1 and 1 GAE per field operation for unpriced native work. Arms are ranked only where the order holds across that band.
5. Fit total cost ∝ N^α per arm over ≥ 4 doublings, bootstrap 95% CI over curves and targets. Report each arm's ratio to rho at every size.

**Prediction (frozen).** rho α = 0.50 ± 0.03; IC-pair α ≈ 2/3; IC-lattice arms α ≥ 0.85 (decomposition probability B²/N with B ≤ p^{1/8} forces ≥ N^{3/4} attempts) and slower than rho at every size by a factor that grows with N; Edwards lattice faster than Weierstrass lattice by a constant factor only.

**Criteria (frozen).**
- SUCCESS: any IC arm with total-cost exponent α whose 95% CI lies entirely below rho's, or whose total cost is below rho's at the two largest sizes with the ratio's CI excluding 1, under every pricing in the band.
- KILL: every IC arm has α's CI entirely above rho's and is slower than rho at every size under every pricing.
- INCONCLUSIVE: otherwise.
