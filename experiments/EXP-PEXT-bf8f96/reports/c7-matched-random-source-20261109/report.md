# Prospective C7 matched-random control instrument

**Scope:** Source-only implementation for H-PEXT-c3a11d / EXP-PEXT-bf8f96. No randomized C7 control, scientific cohort, benchmark or cloud job ran. The experiment remains `review_required` and unfrozen.

The sampler is fixed to seed 20261102, SHA256 counter-domain labels containing the full field-record hash, branch factor pattern and requested scalar class, sixteen distinct quartics per available stratum and a 4,096-draw cap. Four-byte rejection sampling avoids coefficient modulo bias. A fixed least encoded nonsquare multiplies a generated form when needed to match its predeclared scalar class; this preserves its roots, squarefreeness and factor pattern. Nonsquarefree forms, wrong factor patterns and duplicate accepted forms are accounted separately. Exhaustion returns an explicit inconclusive status rather than changing the seed, class or draw cap. The source outputs do not enter the draw labels.

One instrument derives the projective quartic factor-degree pattern from Frobenius gcds and uses exact subset square relations for coefficient-aware geometric and arithmetic ranks. A second instrument splits the conjugate finite supports into disjoint gcd atoms, adds infinity and leading-coefficient character bits, then computes incidence ranks, branch count and component genus. The control refuses a rank/constant-relation discrepancy. Random destinations remain distinct from actual curve/T identity and are not used for same-curve minima or descent claims.

Three fixed F27 software tests pass: all five preexisting branch patterns agree with the two rank instruments; a mocked fixed-form draw exercises scalar normalization and selection without taking randomized control data; invalid forms and an injected instrument discrepancy are rejected. The source sampler is not yet a run stage or bound to a write-once run receipt. Full C7 sampling, custody and finite-resource fit remain prospective under the unchanged experiment ceilings.

## Additive seed-readback increment

The separate `c7_seed_replay.py` module reconstructs each four-byte SHA-256 counter draw and the full rejection/duplicate accounting without invoking the producer sampler. It compares every retained field hash, stratum, seed, draw count, selected form and derived check as one exact record. Both paths now cap SHA rejection at 4,096 blocks per coefficient in addition to 4,096 candidate draws per stratum. A fourth fixed-form software test accepts an unmodified mocked draw and rejects changes to the seed, accounting and selected form; a fifth checks genuine counter-word parity at three fixed positions without selecting control forms. This is source-only replay logic; the fixture does not take randomized control data. The replay shares the existing factor-pattern and two rank instruments, so it is an independent draw/accounting path rather than a separately implemented geometry checker. Write-once run custody and full-stage resource qualification remain open.
