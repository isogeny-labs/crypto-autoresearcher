# Prospective independent C6/C7 control replay

**Scope:** Source-only checker for H-PEXT-c3a11d / EXP-PEXT-bf8f96. The checker was implemented and tested with fixed placeholder payloads. No C6 transport control, C7 randomized draw, scientific cohort, benchmark or cloud job ran. The experiment remains `review_required` and unfrozen.

The future `c67_independent_check_stage.py` entrypoint requires an approved frozen trial plan and the current supervisor authority through the existing custody preflight. It requires the exact `c67-independent-check.json` artifact in one of the existing `n3core`, `n3ext` or `n5` trials. Before replay it checks that the plan binds the bytes of 34 local modules in the static import closure. It then requires the prior write-once custody readback to match the currently retained batch bytes exactly; a missing or changed seal refuses replay.

For every scheduled C6 batch, the checker rebinds the published cohort and class/T source, regenerates all 16 predeclared coordinate slots through `check_all_slots`, and requires exact equality to the retained payload. For every C7 batch, the separate `c7_seed_replay` reconstructs all attempted SHA draws, rejection accounting, selected forms, and the weighted, incidence and character-sum geometry checks. The checker keeps the original requested count when a deterministic draw cap is exhausted and reports incomplete coverage rather than promoting it to a complete control. It writes one hash-bound check summary exclusively; a later check recomputes and compares the existing bytes.

Five fixed software tests pass under Python 3.11 with PyYAML. They check exact replay coverage on synthetic placeholders, refusal of a changed C6 result or failed C7 replay, refusal without sealed custody, future-plan source-hash and artifact gates, write-once summary tamper rejection, and equality of the declared 34-module set to the local static import closure. Mocks replace the control engines in those tests; they verify stage wiring and refusal behavior, not full-cohort runtime or an external independent scientific review.

The future trial plan must bind `c67_independent_check_stage.py` and its local import closure in `source_sha256`, declare `c67-independent-check.json` in each census trial's artifacts, and bind the published schedule and join plans as inputs through the custody component. The approved launcher must call custody admission before any control payload, write each declared result once, seal exact readback, then call this checker. These calls and full-stage CPU/RSS/storage qualification remain unimplemented. The Executor and external Reviewer routes remain open. Original P1-P4/C0-C7/H1 q13 scope and the six-run, 4 GB, 24 CPU-hour, 24-hour, zero-cloud-dollar, no-retry ceilings remain unchanged.
