# C6 common-coordinate transport of a published source

**Scope:** Source-only prospective C6 control for H-PEXT-c3a11d / EXP-PEXT-bf8f96. No scientific cohort, benchmark, cloud job, frozen protocol or approval is claimed.

The component takes a checked published `CandidateBinder` class/T and canonical structure ordinal. A SHA-256 counter stream with seed `20261102` fixes 16 invertible nonrational `PGL2(K)` matrices per selected unit, with draw cap 4096. Four 16-bit words per counter block are accepted only below the largest multiple of `|K|` in `2^16`, so reduction to field elements is unbiased. The record retains attempted block and byte counts. Each matrix has a nonzero lower-left coefficient so the denominator chart is exercised. A repeated matrix among the 16 frozen slots makes the control inconclusive; no adaptive replacement slot is drawn. The component checks the base elliptic quotient map and its rational inverse, composes the projective map, checks the literal binary-quartic scalar and ordinate scaling, and independently replays the composite source map and inverse. It transports **every** member of the original coefficient-conjugate quartic family by the same matrix and independently recomputes square-class ranks, geometric component count and genus. Every equality is checked; all 16 slots are retained.

For a matrix `M` over `K`, the common-transported family `g_i=T_M(f_i)` is generally not an ordinary coefficient-Frobenius orbit. Its exact twisted action is `sigma(g_i)=T_C(g_(i+1))`, with `C=sigma(M) M^-1`; the geometry checker verifies that relation on every form before computing ranks. This preserves the same common coordinate and the full scalar. Applying `M` only to `f_0` and then building an ordinary coefficient orbit instead changes the cover when `M` is outside `PGL2(F_q)`. On a fixed published q5/n3 class 0, T 0 source, the base family has geometric rank 1 and genus 1; that naive orbit under `M=[1,0,5,1]` has rank 3 and genus 17. The common transport retains rank 1 and genus 1. This is a software counterexample to the *naive control construction*, not a scientific P1–P4 counterexample.
