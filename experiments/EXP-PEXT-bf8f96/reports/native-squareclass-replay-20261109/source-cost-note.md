# Independent native square-class replay: prospective cost boundary

**Scope:** Source-only implementation arithmetic for EXP-PEXT-bf8f96. The binary stream and checker do not run a scientific cohort, establish candidate-set completeness, certify descent or approve the experiment. No throughput claim is made here.

The versioned little-endian stream is specified in `implementation/native_squareclass_stream.py`. Its header is derived from the externally supplied published candidate binding: field prime, degree and modulus, literal source quartic and the exact `structures_per_T` index. Every fixed-width row retains a canonical ordinal and matrix plus the producer's geometric rank, branch count, component genus, arithmetic rank and nonsquare-constant flag. The wrapper requires a sealed raw-unit SHA-256, external input/manifest/plan hashes, an externally pinned native binary SHA-256, strict ordinal order and an independent transversal matrix for each ordinal. The native checker independently validates its field modulus, source-form and matrix ranges, stream count, row order and exact EOF.

The native checker has separate polynomial-basis field arithmetic and polynomial gcd/division. It transports the full quartic scalar, computes the coefficient-Frobenius orbit, validates squarefree projective support, splits finite supports into disjoint gcd atoms and adds an infinity bit. GF(2) elimination on atom incidence gives geometric rank; a separate leading-coefficient square-character bit gives arithmetic rank and the constant relation flag. It checks the union branch count and Riemann-Hurwitz component genus. The union branch count may be odd when rank exceeds one; a fixed F27 rank-three row has nine branch points and genus eleven. It does not import producer rank/genus code.

The absolute field cap is 4,096 elements and the row cap is the exact external `structures_per_T`, additionally bounded by 2,000,000 rows. The declared cohorts fit the row cap, including q11/n3's approximately 1.79 million structures per T. Input is read one fixed-width record at a time; each record is 22 bytes. At the largest supported declared field, q=13³=2,197, the two `u16` operation tables occupy `4q²=19,307,236` bytes before inverse/Frobenius/character arrays and polynomial scratch. Field-table construction is O(q²n²) with this direct implementation. Per-row work is bounded by n≤7 quartics of degree≤4, at most 4n finite support atoms, polynomial gcd/division and GF(2) rank elimination. The Python wrapper still parses the sealed JSON unit and checks every canonical ordinal; its object overhead and end-to-end throughput are unqualified.

Fixed software checks rederive all 279+1 exceptional rows from two F27 forms. A third F27 coefficient-twist fixture has 592 exceptional rows, including eight with arithmetic rank one above geometric rank. Tests reject changed producer geometry, arithmetic/constant bits, matrices, ordinals, external binding, binary hash, truncated/trailing streams and a reducible field modulus. One projective structure on a published q3/n5 class/T source form also exercises degree-five arithmetic; this test does not assert that structure's exceptional-set membership. These checks establish arithmetic replay on supplied software fixtures only.

Full-cohort admission still requires exact source-bound measurements or a proven upper bound for candidate generation, this wrapper, native field setup and rows, independent candidate-set replay, write/readback/storage, C3 reversal, mandatory C5 units, controls and supervisor overhead under the unchanged six-run, 4 GB, 24 CPU-hour, 24-hour, zero-cloud-dollar and no-retry ceilings. The q11 synthetic exceptional workload scenario in the compact descent packet is not an observed cohort count. No stage clock or budget can be inferred from the fixture tests.
