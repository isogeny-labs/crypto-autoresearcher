# Answer-free input and post-seal comparison for C5

**Scope:** Source-only design component for H-PEXT-c3a11d / EXP-PEXT-bf8f96. The experiment remains `review_required` and unfrozen. No scientific cohort, benchmark, cloud job or independent C5 review ran.

The public C5 projection is an allowlisted input for one selected unit. It carries the published field, actual curve model, T, quotient quartic, canonical structure range, selected counterexample and Type2 witness ordinals, and hashes/byte count binding the sealed raw candidate unit. A random private nonce salts a commitment to the selected roster row, so its descent status and other private selection fields need not be disclosed to the second implementation. Producer exceptional rows, square-class ranks, genus/minimum values, factor pattern, generic intervals/certificate, summaries and descent status are absent from the public bytes.

The separate checker validates the public projection against an externally read-back digest and published binding. Before opening producer bytes, it requires an externally read-back independent seal digest, a session-receipt hash, an answer hash, and complete exceptional-ordinal plus generic-complement coverage. It then checks the private roster commitment and compares every independent exceptional matrix/rank/branch/genus/constant flag and generic interval against the sealed producer unit. Temporal write-once custody and authentication of the independent session receipt remain caller obligations; this code does not establish that an independent algorithm actually produced the answer.

The fixed F27 software fixture has 279 exceptional and 540 generic structures. Three new projection tests, plus two existing C5 selection tests, pass. Mutations cover public answer injection, changed identity, hashes, private roster, raw bytes, seal, genus, and omitted/duplicate ordinals. Python compilation and `git diff --check` pass. This module is not wired into a production stage because the final certified C5 roster and serving route are still unavailable. No C5 status is promoted.
