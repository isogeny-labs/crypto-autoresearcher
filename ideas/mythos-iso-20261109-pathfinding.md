Standing graph facts used throughout: the supersingular ℓ-isogeny graph G_ℓ(p) over F_{p²} has ⌊p/12⌋+{0,1,2} vertices, is (ℓ+1)-regular, Ramanujan (Pizer), diameter ≤ 2 log_ℓ p + O(1). The F_p-rational "spine" has h(−4p) (+h(−p) if p ≡ 3 mod 4) vertices, i.e. Θ̃(p^{1/2}); its odd-ℓ components (ℓ | p+1) are cycles and its 2-component is a depth-1 volcano when p ≡ 3 mod 4. A faster-than-p^{1/2} classical (p^{1/4} quantum) path algorithm between arbitrary nodes breaks SQIsign key recovery, CGL collision resistance (via OneEnd ≡ EndRing), and CSIDH (via the spine). A proven lower bound on path finding would protect exactly those, because key recovery, EndRing, OneEnd and path finding are all polynomially equivalent (Wesolowski 2022; Page–Wesolowski 2024).

## LEADS

**1. Spine-hit → one endomorphism → End(E_A), skipping the second Delfs–Galbraith phase.** `[known]`
Mechanism: random non-backtracking 2-walk ψ: E_A → E′ of length k ≈ ½log₂p + c; stop when j(E′) ∈ F_p. Then π_p ∈ End(E′) (E′^(p) = E′), and θ = ψ̂∘π_p∘ψ ∈ End(E_A) is non-scalar of degree p·4^k. Feed θ to the OneEnd→EndRing saturation (Page–Wesolowski) and recover the secret ideal class. Attacks: SQIsign key recovery, any scheme with public E_A and secret path from a known E_0. Cost: hitting time ≈ (p/12)/|spine| ≈ p^{1/2}/const walks × k steps × ~100 F_{p²} mults; memory O(1); no spine class-group phase. Delta: none in exponent — this changes only the constant; a genuine break needs a bias toward the spine, which Ramanujan mixing forbids. Obstruction: the saturation step needs a second independent endomorphism or GRH-heuristic order enumeration; its cost at p ≈ 2^{248} is unmeasured. Kill test: at p ∈ [2^{28}, 2^{40}], measure walks-to-spine vs 12/√p baseline and saturation wall-clock; if the constant gain over full Delfs–Galbraith is < 2×, file as measurement only.
CHECKED: H-WESO-516558 (endpoint distribution of non-backtracking norm-2 ideal walks, same sampler); H-ALISO-003 (p1486 Frobenius-midpoint sweep, same Frobenius-conjugate structure); H-ALISO-005 (its verify package).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "for E′/F_p supersingular and ψ: E → E′ an isogeny, ψ̂∘π_p∘ψ ∈ End(E) and ψ̂∘π_p∘ψ ∉ Z".
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1486_frobenius_midpoint_sweep`).

**2. KLPT output non-uniformity as a zero-knowledge gap (SQIsign v1-style responses).** `[adaptation]`
Mechanism: KLPT on the standard order O_0 (i²=−1, j²=−p) outputs J ~ I with Nrd(J)=ℓ^e, e ≈ (7/2)log_ℓ p generic, via a Cornacchia solution on the norm form x²+y²+p(z²+w²) restricted to a coset. The set of reachable J is a tiny, structured subset of the ~ℓ^e paths of that length. Attacks: the ZK heuristic that the response isogeny is independent of the secret, i.e. a security-proof gap, not key recovery. Delta needed: a distinguisher with advantage ≥ 2^{-20} on 10^5 transcripts. Obstruction: SQIsign2D-West removed KLPT from the response; only legacy parameter sets and the signing-key leakage through repeated KLPT calls remain live. Kill test: at p ≈ 2^{64}, generate 10^5 KLPT paths and 10^5 uniform non-backtracking paths of equal length; χ² on the first-10-step kernel subgroups and on the Cornacchia residue classes; no significance at p < 10^{-3} ⇒ drop.
CHECKED: H-WESO-516558 (uniform non-backtracking norm-2 walk endpoint baseline, which this test needs as control); H-SSIQ-d724f2 (census of the standard maximal order and level-N subgroups H_N ⊂ GL₂(Z/N), the same O_0).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "the KLPT map on left O_0-ideal classes has image of density ≤ ℓ^{-δe} among paths of length e".
EXP: none; nearest surface is aburan28/cryptanalysis (shared pcc files with crypto-autoresearcher).

**3. Prescribed-degree paths via admissible-divisor counting in the split window.** `[known]`
Mechanism: an isogeny E_0 → E of degree d exists iff I (the connecting ideal) contains x with Nrd(x) = d·Nrd(I); for B-smooth d the number of ways to split d = d_1 d_2 with d_1 ∈ [⌈d/X⌉, X] (k(d) in the brief's notation) governs how many Kani gluings E×E′ → A exist for dimension-2 ideal-to-isogeny translation. Object: honest-party cost of auxiliary-isogeny generation in SQIsign2D-type signing, and attacker cost of "find an isogeny of degree exactly d" between two public curves (needed by any torsion-image attack). SIDH/SIKE note: the attacker-side use requires published torsion images; SQIsign/CSIDH publish none, so this is an honest-party parameter audit, not an attack. Delta: none; it is a cost model. Obstruction: k(d) is integer-only and says nothing about the quaternion norm equation's solvability. Kill test: tabulate k(d) vs. empirical count of degree-d gluings at p ≈ 2^{30}; discrepancy > 10% ⇒ the integer model is the wrong proxy.
CHECKED: H-SSIQ-dfee7e (admissible divisors of B-smooth d in the split window, integer-only Arm I); H-ALISO-017 (p1243 auxiliary lattice Kani); H-ALISO-014 (p1243 auxiliary discriminant search).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "if d = d_1 d_2 with gcd(d_1,d_2)=1 and N + d = 2^e then the Kani matrix on E×E′ has kernel of order 2^{2e}" (Kani's lemma, dimension 2).
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1243_auxiliary_lattice_kani`).

**4. End(E) from a known path: right-order computation and the number of cycles needed.** `[known]`
Mechanism: given φ: E_0 → E of degree N and End(E_0) = O_0, End(E) = O_R(I_φ) is computed by lattice saturation in B_{p,∞} in O(log² N) quaternion operations — polynomial. The attacker's problem is the missing path; the only algorithmic content is the reverse: how many random cycles through E (endomorphisms) generate a maximal order. Heuristic: two or three suffice (Eisenträger–Hallgren–Lauter–Morrison–Petit); proved: one suffices up to a polynomial reduction (Page–Wesolowski). Object: the lower-bound side — a proof that EndRing requires Ω(p^{1/2}) classical queries in the generic-graph model would protect SQIsign KR and CGL collisions simultaneously. Delta: a query lower bound, not an attack. Obstruction: generic-group-style models do not capture the algebraic structure (the ideal class correspondence is not black-box). Kill test: at p < 2^{20}, count cycles-to-maximal-order; mean > 3 ⇒ the heuristic in the cost models is optimistic.
CHECKED: H-SSIQ-d724f2 (group-theoretic census of the standard maximal order, explicitly "NO ATTACK; NO EXPONENT"); H-ALISO-010 (p1486 parity-center smoothness probe, cycle/center arithmetic in the same order).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "the Z-span of 1 and two endomorphisms with non-commuting reduced traces is an order of rank 4 in B_{p,∞}".
EXP: none; nearest surface is aburan28/crypto-lean (`SplitPrime.Obstruction` module, commit `8187529`).

**5. Ordinary ℓ-volcano descent as an ECDLP preprocessing step — audit of the rejected direction.** `[known]`
Mechanism: Kohel/Fouquet–Morain descent locates E's level in the ℓ-volcano of its F_p-isogeny class in O(ℓ^3 · depth) field ops; the level determines [O_K : End(E)] at ℓ. The rejected hypothesis asked whether choosing a crater or floor representative lowers ECDLP cost; at toy scale (p ∈ {2003, 4001, 6007}, classes certified by Hurwitz–Kronecker mass) it did not. What the rejection protects: standardised curves (P-256: huge disc; secp256k1: disc −3, depth 0) gain no attackable structure from their volcano position. Delta needed to reopen: an exponent-level dependence of rho/collision cost on the conductor, which Pollard-rho's group-order-only dependence rules out. Kill test: repeat at p ≈ 2^{40} with ℓ ∈ {2,3,5}; any cost ratio ≠ 1 ± statistical noise reopens; expected: none.
CHECKED: H-ICINV-6c7920 (rejected_scoped; representative selection within a certified ordinary isogeny class); H-ICINV-82ee6a (Z[π]-endomorphisms on toy prime ladders below 2^{24}); H-ECDLP-f8101e (selecting an isogenous representative via j or endomorphism features).
DISPROVEN: H-ICINV-6c7920 (rejected_scoped) — this lead does not propose representative selection, only measures the volcano cost.
LEAN: no Lean coverage; would need "for ordinary E/F_p the ℓ-volcano depth equals v_ℓ([O_K : Z[π]])".
EXP: none; nearest surface is aburan28/ecbench.

**6. CSIDH spine as a volcano: constant-time ideal-to-isogeny via dimension-2 gluing (Clapoti-style).** `[known]`
Mechanism: for p ≡ 3 mod 4, the F_p-graph is a union of ℓ-cycles (ℓ | p+1) and a depth-1 2-volcano (surface Z[(1+√−p)/2], floor Z[√−p]). Evaluating a class [𝔞] of arbitrary norm is done by finding a,b with a·N(𝔞)+b·N(𝔟) = 2^e and gluing E×E^𝔟 along a (2^e,2^e)-isogeny in dimension 2: O(e) (2,2)-steps, each ≈ 10^3 F_p mults. Object: not an attack — it changes the CSIDH parameter trade-off by making any p viable (no smooth p+1 needed), which shifts the Kuperberg accounting. Delta: none to security; it alters the honest cost by ~10× vs. smooth-p CSIDH. Obstruction: the 2D arithmetic needs 2^e-torsion rational over F_{p²}; the auxiliary ideal 𝔟 needs a norm-equation solve. Kill test: implement at p ≈ 2^{64}; if per-action cost exceeds 100× the smooth-p action the trade-off claim dies.
CHECKED: H-ALISO-016 (p1243 auxiliary geometric principalization, same auxiliary-ideal step); H-ALISO-015 (p1243 auxiliary four-line descent).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "the F_p-rational 2-isogeny graph of supersingular curves for p ≡ 3 mod 4 has exactly two levels".
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1243_auxiliary_geometric_principalization`).

**7. Frobenius-midpoint symmetry of the secret path and whether it leaks the midpoint.** `[speculative]`
Mechanism: in SQIsign, E_0 is over F_p and E_A over F_{p²}; the conjugate path φ^(p): E_0 → E_A^(p) exists, so E_A and E_A^(p) are joined by φ^(p)∘φ̂ of degree N², whose "midpoint" is E_0. Hypothesis: the secret path's intermediate curves E_i and their conjugates are pairwise at distance ≤ 2i, which constrains the walk and might allow a meet-in-the-middle between walks from E_A and from E_A^(p) that must meet on the spine. Attacks: SQIsign key recovery. Delta needed: a MITM that uses the spine constraint to drop the set size from p^{1/2} to p^{1/4}. Obstruction: every spine curve is a valid meeting point and the midpoint E_0 is already known — the constraint gives no new information beyond Lead 1. Kill test: count distinct spine curves reachable in k steps from E_A vs. from E_A^(p); if the intersection is the entire reachable spine set (no selection), the idea reduces to Lead 1 and is closed.
CHECKED: H-ALISO-003 (p1486 Frobenius-midpoint sweep); H-ALISO-004 (its verify sweep); H-WESO-516558 (walk endpoint distribution at tested primes).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "for E over F_{p²}, dist(E, E^(p)) ≤ 2·dist(E, E_0) for any E_0 over F_p".
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1486_frobenius_midpoint_sweep_verify`).

**8. Quantum spine search: Grover over walk seeds with MAXDEPTH accounting.** `[adaptation]`
Mechanism: Grover over seeds s ∈ {0,1}^{k} of non-backtracking walks of length k ≈ log₂ p from E_A with predicate "endpoint ∈ F_p"; success probability ≈ 12·|spine|/p ≈ p^{-1/2}, so ≈ (π/4)·p^{1/4} iterations; then Lead 1's endomorphism + classical saturation. Per iteration: k 2-isogeny steps, each ≈ 3 F_p mults of ~n² Toffoli (n = ⌈log₂ p⌉) plus a Legendre/F_p-membership test. For p ≈ 2^{248}: 2^{62} iterations × 2^{30} Toffoli ≈ 2^{92} Toffoli, but sequential depth ≈ 2^{62+30} far exceeds MAXDEPTH 2^{64}, forcing ≈ 2^{28}-way parallelism and raising total cost accordingly. Object: parameter audit of SQIsign's p^{1/4} quantum claim. Delta: none; it is accounting. Obstruction: the F_p-membership oracle must be reversible and the walk uncomputed. Kill test: a full circuit estimate; if total gates under MAXDEPTH fall below the NIST-I AES-128 Grover figure the parameter set is misfiled.
CHECKED: H-ALISO-012 (p1486 quantum aggregate oracle probe); H-ALISO-013 (p1486 quantum cost-accounting verify).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "Grover with success probability q needs Θ(q^{-1/2}) oracle calls" (standard; not in CryptoLean per brief).
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1486_quantum_cost_accounting_verify`).

**9. Hecke/Krylov spectral cycle finding is memory-dead unless implicit.** `[speculative]`
Mechanism: short cycles through a vertex (endomorphisms) are encoded in diagonal entries of Brandt matrices B(ℓ^k); a Krylov iteration on T_ℓ could in principle expose them. Object: OneEnd for a target E. Obstruction (decisive): the Brandt module has dimension p/12; any explicit Krylov vector costs Θ(p) memory, exponentially worse than the O(1)-memory walk of Lead 1; an implicit variant is just a random walk with extra bookkeeping. Delta needed to live: a sublinear-memory implicit matvec that still extracts a specific cycle, which no spectral method provides. Kill test: at p ≈ 2^{20} compare time-to-first-cycle for Krylov vs. random walk; Krylov slower ⇒ close.
CHECKED: H-ALISO-008 (p1486 Hecke Krylov probe); H-ALISO-009 (p1486 Hecke support-cost probe); H-ALISO-006 (p1486 Hecke degree-pair support probe).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "the Brandt matrix B(ℓ) is the adjacency matrix of G_ℓ(p) with multiplicities".
EXP: none; nearest surface is aburan28/crypto-autoresearcher (autolab package `p1486_hecke_krylov_probe`).

**10. Mixing bound for non-backtracking walks as the Lean target that every walk-based attack cost rests on.** `[adaptation]`
Mechanism: all of Leads 1, 7, 8 assume that after k ≥ (1+ε)·log_ℓ(p) steps the endpoint is within ℓ^{-εk} of uniform in total variation; this follows from the Ramanujan bound |λ| ≤ 2√ℓ on the non-trivial spectrum (Pizer, via Deligne), which is deep, but the derivation from the spectral gap is elementary and formalizable. Object: the heuristic that every cost model in this lane cites. Delta: none; this converts a heuristic to a theorem conditional on the spectral bound. Kill test: a Lean statement with the spectral bound as hypothesis; failing that, an empirical TV-distance table at p ≈ 2^{20}–2^{30} to fix the constant.
CHECKED: H-WESO-516558 (H-S sampler part: endpoint of a uniformly random non-backtracking walk, scoped to tested primes); H-ECDLP-3550b8 (basin size of a deterministic walk with distinguishing density 1/W — the analogous mixing object on the ECDLP side).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "for an (ℓ+1)-regular graph on n vertices with non-trivial adjacency eigenvalues bounded by 2√ℓ, the non-backtracking walk of length k from any vertex has TV distance ≤ C·n·(2/√ℓ)^k ... from uniform" (stated with explicit C).
EXP: none; nearest surface is aburan28/crypto-lean.

**11. CGL hash preimages: fixed-length path with known End(E_0) is poly-time; the trusted-setup repair and its vOW cost.** `[known]`
Mechanism: a CGL preimage is a path of exact length n in G_2(p) from E_0 to a target; with End(E_0) known, KLPT gives a path of length ≈ (7/2)log₂ p directly, so preimage resistance fails for any n above that. Repair: start from a curve of unknown endomorphism ring (trusted setup or a hash-to-curve with unknown End — itself an open problem). With unknown End(E_0), the best generic preimage attack is vOW on two half-walks: set size 2^{n/2}, with memory w the time is ≈ 2.5·√(2^{3n/2}/w) steps; collision (cycle) resistance is p^{1/2} via Lead 1. Object: cost claims for CGL-type hashes. Delta: none to security claims; it fixes what each lower bound protects. Kill test: for p ≈ 2^{40}, n = 60, measure vOW with w = 2^{20} vs. the formula; deviation > 2× revises the model.
CHECKED: H-WESO-516558 (norm-2 ideal walks — the CGL walk is exactly this on the ideal side); H-SSIQ-d724f2 (standard order O_0 whose knowledge enables the KLPT preimage).
DISPROVEN: none in the brief.
LEAN: no Lean coverage; would need "a cycle of length 2n in G_2(p) through E yields a non-scalar endomorphism of degree 2^{2n} of E" (the collision ⇒ OneEnd step).
EXP: none; nearest surface is aburan28/cryptanalysis.
