## LEADS

Wave-1 port leads 1–14 covered exits (tori, matrices, G_a), the scalar ring (Lenstra module, Cheon, GLV lattice, HNP), NFS/FFS readings (two-ring smoothness via lifting, Frobenius-preserves-degree, individual-log descent, large primes), the Gaudry/Jacobian degeneracy, mod-ℓ representations and the Hafner–McCurley rigour port. Second pass picks five source mechanisms that list left open or read in only one of two possible ways.

1. **Boneh–Lipton black-box-field port: the scalar field F_N with implicit multiplication, and the exact price of wave-1's "hidden multiplication"** `[known]`. Forced by wave-1 port lead 3, which stops at "the gap is a hidden multiplication" without pricing it. Mechanism: Boneh–Lipton (1996, recalled) solve DLP in any black-box field of prime order N in L_N[1/2, √2] field operations by lifting implicit representatives to Z and sieving for smoothness; E(F_p)[N] ≅ F_N additively with [k]P as the implicit representative, addition free, multiplication (k,k') ↦ [kk']P exactly CDH. Reduction: ECDLP → L_N[1/2,√2] ≈ 2^{62} CDH calls at N ≈ 2^{256}. Exponent needed: CDH at cost < N^{1/2}/L_N[1/2] ≈ 2^{66} group operations per call versus the best known √N (Shoup's generic bound applies to CDH; Maurer–Wolf/den Boer make CDH ⇔ DL with auxiliary smooth-order curves over F_N, so a sub-√ CDH algorithm is already a sub-√ DL algorithm). Obstruction: circularity — every scalar-ring port that multiplies logs is a CDH algorithm in disguise. Falsification test (calibration only, no oracle is ever run against an unknown k): instrument `cryptanalysis/include/ca_indexcalc.h` at p ∈ [2^{40}, 2^{56}] to count field multiplications per solved log; the lead is killed as a route if that count (the oracle budget of any scalar-ring port) exceeds √N·2^{−10} already below 2^{56}, which the L[1/2] formula predicts it does not (≈2^{17} vs 2^{28} at 56 bits) — i.e. the budget is real but the per-call price is the whole problem. Rows: KR-RHO-13bf67, KR-RHO-53c89f.

2. **NFS commutative-diagram port through a public isogeny pair (φ, φ̂): doubly-smooth points and the size-correlation certificate** `[adaptation]`. Forced by wave-1 port lead 5, which read "two rings mapping to F_p" as lifting to characteristic zero; the other reading — two curves mapped to each other by φ: E→E′ of small degree ℓ with φ̂φ = [ℓ] — was omitted. Mechanism: NFS gains because a − bm and a − bα are both *small* and smooth with Dickman probability; the elliptic analogue needs x(P) < L and x(φ(P)) < L to co-occur more often than L²/p, giving relations Σφ(P_i) = ΣP′_j with one extra unknown u = log_{P′}φ(P). Reduction: relation supply on E ⊔ E′ at yield π_{LL}·(B^m/N)(B′^m/N′). Exponent needed: correlation ratio ρ = π_{LL}·p/L² ≥ p^{δ}, δ > 0; best known is the Hecke/isogeny lane's null. Obstruction: x∘φ is a degree-ℓ rational function; for L > p^{1/2+ε} Erdős–Turán–Koksma plus Weil (recalled) force ρ = 1 + O(ℓ√p log²p/L²), and below √p nothing is provable but no mechanism for excess exists. Falsification test: Vélu isogenies ℓ ≤ 13 on prime-order curves at p ≤ 2^{26} from `crypto/docs/ECDLP_CALIBRATION_PRIMES.md`, L = p^{0.4}, count π_{LL} exactly; port is dead if ρ ∈ [0.8, 1.25] for every (p, ℓ) — read `cryptanalysis/experiments/ecdlp-hecke-cross-discriminant-20261012` first, it may already contain this count under another name. Rows: KR-RHO-755e35, KR-IC-5931ee.

3. **Kedlaya–Umans / multipoint-evaluation port of the μ_B resultant tower across many targets, and the target-degree identity that prices it** `[adaptation]`. Forced by the wave-1 relations record "Multiplicative-subgroup factor base x^B = 1 … resultant tower" (per-target cost only) and by KR-IC-f3da82 (trace replay is Gröbner-side; the exact-polynomial side is unfiled). Mechanism: the tower's final univariate G_B(X; x_R) is the specialisation at T = x_R of one bivariate G_B(X,T) = ∏_{ζ∈μ_B^{m−1}} S_{m+1}(X, ζ, T) mod (X^B − 1); precompute it once, then amortise targets by multipoint evaluation in T. Reduction: per-target decomposition → Õ(B) after a precomputation of size B·deg_T G_B. Exponent needed: B·deg_T G_B < N^{1/2}; identity: deg_T G_B = 2^{m−1}B^{m−1} generically and every T-root is x(±P_1±…±P_m), so deg_T ≥ #distinct sums ≈ 2^{m−2}B^{m−1}/(m−1)!·(1 − collisions); with B^m ≈ m!N the object has ≥ cN coefficients. Obstruction: the only loophole is massive coincidence among sums, i.e. additive-energy excess of F_B in E(F_p), which the barriers lead "energy–Freiman tautology" equates with discrete-log structure. Falsification test: compute G_B for m = 3, B ∈ {7,13,19,31}, measure deg_T and the collision deficit; dead if deficit is O(B). → RECORD 1.

4. **Bilinear section-coefficient (Kipnis–Shamir / support-minors) presentation of the L((m+1)O) incidence system, with the Faugère–Safey El Din–Spaenlehauer bihomogeneous regularity bound** `[adaptation]`. Forced by the wave-1 relations record "Three presentations of one zero-dimensional membership system (flat, chained S_3, incidence determinant)": the determinant presentation eliminates the section coefficients c by Cramer; the MinRank literature's lesson is that keeping the kernel vector as variables (bilinear modelling) can lower the Gröbner degree wall. Mechanism: unknowns c ∈ P^m (f_c = Σc_jφ_j ∈ L((m+1)O)), points (x_i,y_i); equations f_c(P_i) = 0 (bilinear), f_c(R) = 0 (linear in c), curve, membership x_i^B = 1. Reduction: PDP → a system whose bilinear part obeys d_reg ≤ min(n_c, n_p) + 2 for generic bilinear systems (FSS 2011, recalled). Exponent needed: F4 wall independent of B (i.e. ≤ B + 2) while the determinant/flat walls grow with B; best known: wall ≈ B + const for all presentations tried. Obstruction: the binomials x_i^B − 1 are not bilinear and the FSS bound does not cover them; expectation is a null. Falsification: m = 3, B ∈ {7,13,19}, same solver and ordering, compare walls. Surfaces: `crypto/RESEARCH_GROEBNER_F4.md`, `crypto-autoresearcher/groebner_compare`, `crypto/research/semaev_alternatives_audit_20261104`. → RECORD 2.

5. **Structured AG-code decoding port (error-correcting pairs, Lee–O'Sullivan, Guruswami–Sudan) for the elliptic evaluation code: decomposition is decoding at exactly twice the reachable radius** `[known]` (closure with a number). Forced by the wave-1 wildcards record "Elliptic AG code: decomposition ⟺ weight-m codeword in the dual; ISD imports", which imported only exponential ISD and left the polynomial-time structured decoders unexamined. Mechanism: with D = Σ_{P∈F}P + R and G = (m+1)O, C_Ω(D,G) has designed distance deg G − 2g + 2 = m + 1 (g = 1); a decomposition of R is a weight-(m+1) codeword supported at R, i.e. a codeword at distance m from the unit vector e_R. Reduction: PDP → decoding e_R at radius m in a code of designed distance m + 1. Exponent needed: polynomial-time decoding at radius m; best known structured radius: unique (d* − 1 − g)/2 = (m − 1)/2, list (Johnson) ≈ (m+1)/2 — a factor-2 gap for every m, independent of B. Obstruction: the gap is not information-theoretic (expected list size at radius m is the decomposition count ≈ B^m/N ≈ 1); it is the known hardness of beyond-Johnson decoding, and Cheng (2008, recalled) ties elliptic-code minimum distance to elliptic subset sum — the port returns the problem it started from. Falsification test: `crypto/sage` script building C_Ω over a toy base and running Sage's AG unique/list decoders on e_R for 10^3 targets; the closure is wrong if any structured decoder returns a relation at rate above the chance rate of relations within radius (m−1)/2 (which is zero). Rows: KR-IC-5a43e5, KR-IC-5931ee, KR-RHO-13bf67.
