1. **Small-degree endomorphism coincidence relations ([j] and norm-ℓ CM maps)** `[adaptation]`. Forced by the wave-1 port lead "Koblitz Frobenius-invariance → μ₃-graded Semaev, capped at 3" and the sweep item "Hecke/volcano position for j = 0 [known]", which note that on secp256k1 every horizontal ℓ-step is an endomorphism but do not price it as a *relation source*. Mechanism: on y² = x³ + b with End = Z[ω], every prime ℓ ≡ 1 (mod 3) gives α = a + bω of degree ℓ = a² − ab + b² (3+ω: 7, 4+ω: 13, 5+2ω: 19) acting on E(F_p) as the known scalar λ_α = a + bλ mod N; any curve has [j] of degree j². x(αP) = f_α(x(P)) is a degree-ℓ rational function, so a pair P ∈ F, αP ∈ F with F = {x < L} yields a weight-2 relation log(αP) − λ_α·log P = 0 without any summation polynomial. Reduction: ECDLP relation supply → solutions of N_α(x) − y·D_α(x)² ≡ 0 (mod p) with |x|,|y| < p^β (bivariate small roots). Cost: expected coincidences per endomorphism are |F|²/N = N^{2β−1} < 1 for every β < 1/2, so filling B = N^β rows needs ≈ N^{1−β} endomorphisms, i.e. degrees up to N^{1−β}; the Coppersmith region β < 1/(ℓ+1) (heuristic) is empty of solutions on average. Exponent needed: none; honest delta 0 versus KR-RHO-13bf67. Obstruction: the count is a birthday count over a non-group-structured predicate, and only orbit-closed bases (KR-IC-b0fcda) convert endomorphisms into system savings; intervals are never [j]- or α-closed. Falsification test: at p ≈ 2²² with β ≈ 0.6 (so N^{2β−1} ≈ 20 per map) count coincidences for α ∈ {[2],[3],3+ω,4+ω} on j = 0 calibration curves (`crypto/docs/ECDLP_CALIBRATION_PRIMES.md`, endomorphism tables in `RESEARCH_SECP256K1_CM.md` / `secp256k1_cm_audit`) against a random-permutation control; a ratio ≥ 2 that survives 10³ curves would be the first evidence of coordinate–endomorphism correlation and is the only thing that keeps the lead alive.

2. **Dilate-union factor base F_s = ∪_{j≤s}[j⁻¹]F: s^m more candidates, the same B unknowns** `[adaptation]`. Forced by wave-1 sweep "Half-arity claw / k-SUM [known]" (which enlarged the *search* but not the base) and by IDEA-20260726-002 (φ-orbit unions; recalled from the ledger index) whose finite-orbit trick has no analogue under scalar dilation. Mechanism: membership of R costs x(jR) for j ≤ s (s−1 additions); since log([j⁻¹]P) = j⁻¹log P, relations over F_s are linear in the B logs of F with coefficients ∏j, so the matrix stays B×B while the candidate pool is sB. By IDEA-20260805-a25f11 (recalled) the *mean* decomposition count is exactly C(2|F_s|+m−1, m)/N, so the mean gain s^m is a theorem; what is open is whether decomposition over F_s costs less than over a plain interval base of size sB. Reduction: relation stage of prime-field Semaev IC → the same enumeration or F4 problem on a union of s degree-j² preimages of an interval. Cost: enumeration gives relation stage m!N/s, identical to a plain base of size sB; the twisted algebraic system S_{m+1}(x([J/j_i]P_i); x([J]R)) inflates degrees by (J/j_i)², so the algebraic route is worse. Exponent delta 0 (KR-RHO-13bf67; floor of IDEA-20260727-003). Obstruction: the LA saving s^ω lands in the stage that is never the bottleneck over F_p. Falsification (of the "no discount" claim): charged ops per collected relation over F_s falling below 0.5× that of a plain size-sB base at s = 8 on two calibration primes. Record below.

3. **Interpolation-degree and linear-complexity barrier for the ECDL function** `[known]`. Forced by wave-1 sweep "Learned predictor of k-bits from x(kP) [speculative]", which argued flatness via exponential sums but did not name the already-proved barriers, and §3 has no row for them. Mechanism (recalled literature, constants to be re-verified by the filer): Lange–Winterhof (COCOON 2002; and the Boolean-function sequel) prove that any polynomial f ∈ F_p[X] with f(x(kP)) = k on a set S of logarithms has degree bounded below essentially linearly in |S| (with explicit loss), and Lange–Shparlinski prove near-maximal linear complexity of the sequence x(kP) over F_p; together they foreclose "low-degree model of the discrete log on a large set" exactly where the learned-predictor lead lives. Reduction: ML/statistical attack → existence of a low-complexity model, which these theorems deny up to polynomial loss. Exponent: no algorithm; delta 0. Obstruction to using it as a barrier: the theorems bound polynomial/linear models, not arbitrary circuits, so they cap only the polynomial-feature regime. Cheap test (a KR-row candidate, not an attack): at p ≈ 2¹³ compute the exact minimal interpolation degree d_min(L) of k ↦ x(kP) on S = [1, L] by truncated-Vandermonde rank, against random-label controls; prediction d_min = L − O(1) in both arms. Repository surface: a Sage script under `crypto/research/scripts` beside the hybrid-sum census; outcome feeds a new `knowledge/frontiers/ecdlp/barriers/KR-*` row.

4. **F_{p²} box base traced to E(F_p): Weil restriction of a conjugate-pair decomposition** `[adaptation]`. Forced by the wave-1 transfer record "Null control for the ascent lane" (Gaudry's *subspace* base over F_{p³} is just E(F_p)) and the wildcards Coppersmith record (x-interval only): neither tried the non-subspace box base {S ∈ E(F_{p²}) : x(S) = a + b√ν, a,b < L}, |F_box| ≈ L². Mechanism: Tr(S) = S + S̄ ∈ E(F_p) (equals 2·proj_E(S) when gcd(N, #E′) = 1), so F_tr = Tr(F_box) ⊂ E(F_p) has ≈ L² points and membership of R ⇔ S_3(a+b√ν, a−b√ν, x_R) = 0 with small a,b, a total-degree-4 bivariate small-root problem over F_p. Reduction: decomposition R = ΣTr(S_i) ⇔ S_{2m+1}(x_1, x̄_1, …, x_m, x̄_m; x_R) = 0; the polynomial is Galois-fixed, so Weil restriction yields ONE F_p equation in 2m unknowns of size L, degree 2^{2m} per conjugate pair, versus one equation in m unknowns of size L² and degree 2^{m−1} for the plain interval base of the same size B = L². Same yield B^m/(m!N), strictly higher degree per bit of unknown: cost exponent cannot drop below the F_p interval case (closed in closed form; delta 0 versus KR-IC-5931ee / KR-IC-46d822). Obstruction: conjugate symmetry collapses the two restricted equations into one, so the extension buys variables but no equations. Falsification: an F4 run (`RESEARCH_GROEBNER_F4.md` pipeline, `RESEARCH_DIEM_DESCENT.md` for the ascent bookkeeping) at p ≈ 2¹⁶, m = 2, showing the restricted system's solving degree *below* the plain interval system's at equal B.
