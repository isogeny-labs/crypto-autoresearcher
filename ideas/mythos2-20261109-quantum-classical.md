For secp256k1, N−1 = 2^6·3·149·631·q₅₇·q₆₈·q₁₀₈ (bit lengths recalled, re-verify), so there are low-order labels χ_2,χ_3,…,χ_631 equal to k^{(N−1)/ℓ} mod N. Reduction: ECDLP → one label χ_ℓ(k) from (P,Q) plus CRT over a generating set of characters. Exponent: any sub-√N label algorithm breaks ECDLP outright — Hästad–Näslund-type hard-core results (recalled) make χ_2(k) with advantage ε give k in poly(1/ε); the shadow is all-or-nothing. Obstruction: computing χ_ℓ(k) needs the ℓ-th power map on the torsor, i.e. [k^{(N−1)/ℓ}]P, which is Cheon's auxiliary input, forbidden here; the wave-1 port record "Pohlig-Hellman on the scalar torsor … one power-residue character of the logarithm" is the nearest filed object (id to resolve in `ledger/proposals`). 6. **Statistical label propagation through point addition — the Wagner/Kuperberg merge** `[adaptation]`. Mechanism: both sieves keep a combined element only when a label zeroes, so the label must be a function of the summands' labels. IDEA-20260806-c5d183 (as cited in IDEA-20260806-071255) proves no deterministic propagating projection exists on a prime-order group; Delaplace–May over F_{p²} pay p^{1.314} for the same reason (KR-RHO-5b1c0a). Exponent: a 2^j-list merge with lists N^{1/(1+j)} needs t=log₂N/(1+j) zeroed bits, i.e. 2^{3t} ≥ N for j ≤ 2, exactly where the Weil envelope |T/E−1| ≤ C·2^{3t}Λ(p)³/p is vacuous at every size.
