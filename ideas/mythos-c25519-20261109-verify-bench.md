## LEADS

Baseline costs read from the BRIEF excerpts (one `fe_mul` call counted as `M` whether or not the operands are equal, because `x25519.rs` squares with `fe_mul(&a,&a)` and multiplies `a24` with `fe_mul`):

- `x25519.rs` ladder step: 10M + 8a (4 of the 10 are squarings done as `fe_mul`, 1 is `a24·E`), 255 steps + 1I, `if s == 1 { swap }` is a secret-dependent branch.
- `ed25519.rs` `add`: 11M + 6a (`2·T1`, `d·T2`, `2·Z1` are three full `fe_mul` calls). `double`: 5M + 4S (`2·Z²` as `fe_mul`). `scalar_mul`: double-and-add, scalar-dependent op trace.

Standing assumptions for every count: $p=2^{255}-19$, $a=-1$, $d=-121665/121666$ non-square, $-1$ square ($p\equiv 5\pmod 8$), $B=1$, cofactor 8, $E(\mathbb F_p)[2^\infty]\cong\mathbb Z/8$.

1. **[adaptation] Sage symbolic verifier `tools/ecc/verify_formulas.sage`.** Work in $R=\mathbb Q[a,d,X_1,Y_1,Z_1,T_1,X_2,Y_2,Z_2,T_2]$ modulo the extended-coordinate ideal $I=(aX_i^2+Y_i^2-Z_i^2-dT_i^2,\;X_iY_i-Z_iT_i)_{i=1,2}$. For each addition law output $(X_3,Y_3,Z_3,T_3)$ assert $aX_3^2+Y_3^2-Z_3^2-dT_3^2\in I$, $X_3Y_3-Z_3T_3\in I$, $X_3(Z_1Z_2+dT_1T_2)-Z_3(X_1Y_2+Y_1X_2)\in I$, $Y_3(Z_1Z_2-dT_1T_2)-Z_3(Y_1Y_2-aX_1X_2)\in I$ (i.e. agreement with the affine law $x_3=\frac{x_1y_2+y_1x_2}{1+dx_1x_2y_1y_2},\ y_3=\frac{y_1y_2-ax_1x_2}{1-dx_1x_2y_1y_2}$). Then over $\mathbb F_p$ check $O=(0,1)$, $T_2=(0,-1)$, $T_4=(\sqrt{-1},0)$, $T_8=[\ell]P$ for random $P$: $P+O=P$, $P+(-P)=O$, $2T_4=T_2$, $2T_2=O$, $T_8+T_8=2T_8$, $[8\ell]B=O$. Symmetry: proving over symbolic $a,d$ then specialising $a=-1$ is the coordinate-scaling $x\mapsto x/\sqrt{a}$ done once. Surface: new `tools/ecc/`, CI job `verify-formulas`.

2. **[adaptation] Exhaustive small-field analogue `tools/ecc/small_field_exhaustive.py`.** Select $p'\equiv 5\pmod 8$, $2^7<p'<2^{10}$, and a non-square $d'$ such that $-x^2+y^2=1+d'x^2y^2$ has $n=\#E=8\ell'$ with $\ell'$ prime and twist order $2p'+2-n=4\ell''$ with $\ell''$ prime (the script searches; no numbers are hard-coded). Because $d'$ is a non-square the only rational 2-torsion point is $(0,-1)$, so $E[4]$ is cyclic exactly as on Curve25519. Montgomery analogue: $A'=2(1-d')/(1+d')$, $a_{24}'=(A'+2)/4$; the $x$-only ladder is $B$-independent. For all $n^2$ ordered pairs compare every projective law to the affine complete law; record the exception set exactly. Symmetry exploited: the same formulas, same residue classes of $p$, same torsion structure. Surface: Python module beside `src/ecc/`, runs in seconds.

3. **[adaptation] Cross-model differential test Edwards↔Montgomery.** With $s=\sqrt{-486664}$ chosen so that $x_{\rm ed}(B)$ equals the RFC 8032 base $x$ (the even root): $u=\frac{1+y}{1-y},\ v=\frac{s\,u}{x}$; inverse $y=\frac{u-1}{u+1},\ x=\frac{s\,u}{v}$. Exceptional loci: $O\leftrightarrow\infty$, $(0,-1)\leftrightarrow(0,0)$; $u=-1$ carries no $\mathbb F_p$-point because $A-2=486660$ is a non-square (equivalently $d$ non-square); $u^2+Au+1$ has no root since $A^2-4=486660\cdot486664$ is non-square, so $(0,0)$ is the only $v=0$ point; $T_4\leftrightarrow(1,\pm s/\sqrt{-1})$. Assertion: `x25519(k, 9) == bytes((1+y)/(1-y))` for $(x,y)=[\mathrm{clamp}(k)]B$ from `ed25519.rs`, on the RFC 7748 §5.2 vectors already in the test module and 1000 random scalars. Surface: `src/ecc/x25519.rs` tests + `src/ecc/ed25519.rs` (expose `scalar_mul` under `cfg(test)`).

4. **[adaptation] Operation-counting harness (`opcount` feature).** Thread-local counters inside `fe_mul`, `fe_sq`, `fe_add`/`fe_sub`, a new `fe_mul_const`, `fe_inv`, and `cswap`; `opcount::reset()/take()` return `{M,S,c,a,I,cswap}` and an op-kind trace. Tests assert exact counts against a claims table `src/ecc/opcount_claims.rs`; a second assertion compares traces for two scalars (all-zero clamped, all-0xff clamped) and fails if they differ — the branch-free/uniform-read check. Surface: `src/ecc/curve25519.rs`, `src/ecc/opcount.rs`.

5. **[adaptation] `ecbench` method `--method {x25519-vb, ed25519-fb, ed25519-vb} --json`.** Exposes `crypto::ecc::bench::run(method, iters)` returning `{ops, ns_per_scalarmult, claimed, verdict}`; verdict is `pass` iff counted ops equal the claim in the claims table. Wall time is reported but is never the pass criterion (repository rule: wall time is never a bound). Surface: `ecbench`, `crypto` lib.

6. **[adaptation] Ladder step with true squarings and a constant multiply.** $A=X_2+Z_2,\ AA=A^2,\ B=X_2-Z_2,\ BB=B^2,\ E=AA-BB,\ C=X_3+Z_3,\ D=X_3-Z_3,\ DA=D\cdot A,\ CB=C\cdot B,\ X_3'=(DA+CB)^2,\ Z_3'=u\,(DA-CB)^2,\ X_2'=AA\cdot BB,\ Z_2'=E\,(AA+a_{24}E)$. Count 5M + 4S + 1c + 8a (was 10M + 8a). Complete for all $u\in\mathbb F_p$ including twist points and $u=0$; outputs $Z_2'=0\Rightarrow$ all-zero result, matching RFC 7748. Symmetry: $x$-only Kummer quotient $P\sim -P$. Replaces `ladder` in `x25519.rs`. Certified by lead 4: exact `{M:5,S:4,c:1,a:8}` per step.

7. **[adaptation] Constant-time cswap and uniform trace for the ladder.** Replace `if s==1 {mem::swap}` by a mask-based swap counted as `cswap`; assert 256 cswaps and identical op traces for all scalars. With `BigUint` the field ops themselves are not constant-time; the assertion certifies only the control flow, and the record says so. Surface: `x25519.rs`.

8. **[adaptation] Ed25519 unified addition with $k=2d$ hoisted.** $A=(Y_1-X_1)(Y_2-X_2),\ B=(Y_1+X_1)(Y_2+X_2),\ C=k\,T_1T_2,\ D=2\,(Z_1Z_2),\ E=B-A,\ F=D-C,\ G=D+C,\ H=B+A;\ X_3=EF,\ Y_3=GH,\ T_3=EH,\ Z_3=FG$. 8M + 1c + 9a (was 11M + 6a). Complete on all of $E(\mathbb F_p)$: $F=2Z_1Z_2(1-dx_1x_2y_1y_2)$, $G=2Z_1Z_2(1+dx_1x_2y_1y_2)$ and $dx_1x_2y_1y_2=\pm1$ would make $\pm d$ a square (Bernstein–Lange completeness theorem; $-1$ is a square so both cases force $d$ square). Replaces `EdPoint::add`.

9. **[adaptation] Niels mixed addition for fixed-base.** Table entry $(y_2+x_2,\ y_2-x_2,\ k\,x_2y_2)$, $Z_2=1$: $A=(Y_1-X_1)(y_2-x_2),\ B=(Y_1+X_1)(y_2+x_2),\ C=T_1\cdot(kx_2y_2),\ D=2Z_1$, then $E,F,G,H$ and 4M as in lead 8. 7M + 0c + 7a. Negation symmetry $x\mapsto -x$: $-(y+x,\ y-x,\ kxy)=(y-x,\ y+x,\ -kxy)$, so a signed-digit table needs half the entries and negation is one cswap plus one negation, branch-free. Cached-$Z$ variant $(Y_2+X_2,\ Y_2-X_2,\ 2Z_2,\ kT_2)$: 8M + 0c + 6a for variable-base windows. Surface: new `ed25519.rs` table code.

10. **[adaptation] Doubling with projective output (HCD §3.3, $a=-1$).** $A=X^2,\ B=Y^2,\ C=2Z^2,\ E=(X+Y)^2-A-B,\ G=B-A,\ F=G-C,\ H=-(A+B);\ X_3=EF,\ Y_3=GH,\ Z_3=FG$, and $T_3=EH$ only when the next operation is an addition. 3M + 4S + 8a projective, 4M + 4S + 8a extended (was 5M + 4S). Complete: affinely $F=dx^2y^2-1$, $G=1+dx^2y^2$, nonzero by the lead-8 argument; at $O$: $F=-2Z^2$, $G=Z^2$. Window $w$: $(w-1)$ projective doublings + 1 extended doubling + 1 mixed add $=(3w+8)M+4wS$ per window with Niels tables. Replaces `EdPoint::double`.

11. **[adaptation] Dedicated $d$-free (dual) addition as the planted incompleteness control.** $A=X_1X_2,\ B=Y_1Y_2,\ C=Z_1T_2,\ D=T_1Z_2,\ E=D+C,\ F=(X_1-Y_1)(X_2+Y_2)+B-A,\ G=B-A,\ H=D-C;\ X_3=EF,\ Y_3=GH,\ T_3=EH,\ Z_3=FG$. 8M + 0c + 7a (7M mixed with $Z_2=1$). Affinely $x_3=\frac{x_1y_1+x_2y_2}{y_1y_2+ax_1x_2},\ y_3=\frac{x_1y_1-x_2y_2}{x_1y_2-x_2y_1}$. Exceptional exactly when $Q-P\in\langle T_4\rangle=\{O,(0,-1),(\pm\sqrt{-1},0)\}$: $F=0\Leftrightarrow x_1y_2=x_2y_1$ and the two further solutions on the line have $x^2=1/(dy_1^2)$, non-rational since $d$ is non-square; $G=0\Leftrightarrow y_1y_2=x_1x_2\Leftrightarrow Q=P\pm T_4$ by the same argument. Inside the prime-order subgroup the only exception is $P=Q$. Symmetry: this is the dual addition law of the pair $(x_3,y_3)$ under the involution swapping the two Edwards laws. Surface: `ed25519.rs` behind a test-only flag; the exhaustive harness must report exactly $4n$ exceptions or it is broken.

12. **[adaptation] Okeya–Sakurai $y$-recovery for the ladder (Costello–Smith form, $B=1$).** Inputs: affine $Q=(u_Q,v_Q)$, $v_Q\ne0$, and $(X_2{:}Z_2)=[k]Q$, $(X_3{:}Z_3)=[k+1]Q$ with $Z_2Z_3\ne0$. $v_1=u_QZ_2,\ v_2=X_2+v_1,\ v_3=(X_2-v_1)^2X_3,\ v_1'=2A\,Z_2,\ v_2\leftarrow(v_2+v_1')(u_QX_2+Z_2)-v_1'Z_2,\ Y=v_2Z_3-v_3,\ w=2v_Q\,Z_2Z_3,\ X=wX_2,\ Z=wZ_2$; $[k]Q=(X/Z,\ Y/Z)$. 10M + 1S + 1c + 7a. Fails exactly when $[k]Q=O$, $[k+1]Q=O$, or $Q\in E[2]$ — certified exhaustively by lead 2. Buys a full-point output from `x25519.rs` so lead 3 can compare both coordinates against `ed25519.rs`. Surface: `x25519.rs` (`ladder_full`, test-only at first).

13. **[adaptation] Ladder completeness certificate on curve ∪ twist.** On the small analogue, for every $u\in\mathbb F_{p'}$ and every $k\in[0,\max(8\ell',4\ell''))$: `ladder(k,u)` equals $x([k]P)$ computed by affine Montgomery arithmetic on $E$ or $E^t$ (whichever $u$ lies on), with $x(O):=0$ and `fe_inv(0)=0`.
