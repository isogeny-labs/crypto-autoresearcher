# Curve25519 — the Montgomery ladder and its coordinate systems

**Notation used throughout.** $p = 2^{255}-19$. Montgomery $E:\ v^2 = u^3 + Au^2 + u$, $A = 486662$, $B = 1$. $a_{24} := (A-2)/4 = 121665$ (pairs with $AA + a_{24}E$); $a_{24}^{+} := (A+2)/4 = 121666$ (pairs with $BB + a_{24}^{+}E$). Edwards25519: $-x^2 + y^2 = 1 + d x^2y^2$, $d = -121665/121666$; $a_{24}^{+} = 1/(1+d)$, $a_{24} = -d/(1+d)$. Maps (RFC 7748 sign convention): $u = (1+y)/(1-y)$, $v = c_0\,u/x$, $x = c_0\,u/v$, $y = (u-1)/(u+1)$ with $c_0 = \sqrt{-486664}$. Exceptional loci of the maps: $y = 1 \leftrightarrow u = \infty$ (identity), $y = -1 \leftrightarrow u = 0$ ($T$, order 2, $v=0$), $u = -1$ is on the twist (order 4 there), $u = 1$ is the order-4 point of $E$ ($y = 0$, $x = \pm\sqrt{-1}$). $T := (0,0)$. $R_0 = kP_1$, $R_1 = (k+1)P_1$ is the ladder invariant.

**Current repository cost (the comparison target).** `x25519.rs::ladder` runs 255 iterations ($t = 254,\dots,0$) of 10 `fe_mul` + 8 `fe_add/fe_sub` (the four squarings and the $a_{24}$ product are executed as `fe_mul`; `fe_sq` exists in `curve25519.rs` but is unused here), one `std::mem::swap` behind a secret-dependent `if`, then 1 `fe_inv`. Per scalar: **2550 fe_mul + 1 I + 255 secret-dependent branches**. The doc comment reads "`A24 = (486662 + 2) / 4 = 121665`": the arithmetic is wrong ($(A+2)/4 = 121666$); the constant 121665 is $(A-2)/4$ and is correct for the `aa + a24·e` form the code uses. `ed25519.rs::EdPoint::scalar_mul` is variable-time double-and-add: $\approx 252\cdot(4M+4S+1\text{ mul-by-2}) + \approx 126\cdot 11M \approx 2650$ fe_mul $+ 1008$ fe_sq for a 253-bit scalar, with scalar-dependent operation count.

## LEADS

### L1 `[known]` — RFC 7748 XZ step (baseline; what the repo implements)
Model: $u$-line $\mathbb{P}^1$, $(X{:}Z)$, $u = X/Z$; inputs $(X_2{:}Z_2) = u(R_0)$, $(X_3{:}Z_3) = u(R_1)$, affine $x_1 = u(P_1)$.
$$A = X_2+Z_2,\quad B = X_2-Z_2,\quad AA = A^2,\quad BB = B^2,\quad E = AA-BB,$$
$$C = X_3+Z_3,\quad D = X_3-Z_3,\quad DA = D\cdot A,\quad CB = C\cdot B,$$
$$X_4 = AA\cdot BB,\quad Z_4 = E\,(AA + a_{24}E),\quad X_5 = (DA+CB)^2,\quad Z_5 = x_1\,(DA-CB)^2 .$$
Identities behind it: $X_4 = (X_2^2 - Z_2^2)^2$, $Z_4 = 4X_2Z_2(X_2^2 + AX_2Z_2 + Z_2^2)$; $DA + CB = 2(X_2X_3 - Z_2Z_3)$, $DA - CB = 2(X_3Z_2 - X_2Z_3)$, so $(X_5{:}Z_5) = (Z_1(X_2X_3-Z_2Z_3)^2 : X_1(X_2Z_3 - X_3Z_2)^2)$ with $Z_1 = 1$.
Count: **5M + 4S + 1c + 8a** per bit (repo executes it as 10 fe_mul + 8a).
Completeness: doubling is defined on all of $\mathbb{P}^1(\mathbb{F}_p)\setminus\{(0{:}0)\}$: $Z_4 = 0 \iff X_2Z_2(X_2^2+AX_2Z_2+Z_2^2) = 0 \iff X_2Z_2 = 0$ because $u^2 + Au + 1$ is irreducible ($A^2-4 = (A-2)(A+2)$, $A+2$ a square, $A-2 = 4\cdot121665$ a non-square), and then $X_4 = Z_2^4$ or $X_2^4 \ne 0$. Differential addition is undefined exactly when $P_1 \in \{\mathcal O, T\}$: it realises $u(P{+}Q)\,u(P{-}Q) = (u_Pu_Q-1)^2/(u_P-u_Q)^2$, whose left side carries the factor $u(P-Q) \in \{\infty, 0\}$. On the wire only $u = 0$ reaches this: the first step then yields $(X_5{:}Z_5) = (0{:}0)$ and the output is $0$ only because `fe_inv(0) = 0`. The point at infinity is $(X{:}0)$, $X\ne0$, and is a fixed point of doubling. Twist inputs ($u$ with $u^3+Au^2+u$ a non-residue) are processed identically since $B$ never appears. Symmetry: quotient by $[-1]$ only.
Constant-time: the formula is branch-free; `if s == 1 { swap }` is not; `BigUint` is never. Surface: `x25519.rs::ladder` — use `fe_sq` for $AA, BB, (DA{\pm}CB)^2$; fix the $a_{24}$ comment. Script: `tests/ecc/ladder_forms.rs::rfc7748_vectors` asserts the RFC 7748 §5.2 vectors and the 1-, 1000-iteration vectors unchanged.

### L2 `[adaptation]` — projective difference $(X_1{:}Z_1)$
Replace the last two lines of L1 by $X_5 = Z_1(DA+CB)^2$, $Z_5 = X_1(DA-CB)^2$: **6M + 4S + 1c + 8a**. Buys inversion-free entry when $P_1$ arrives as Edwards $(Y_1{:}Z_1)$: $(X_1{:}Z_1)_M = (Z_1 + Y_1 : Z_1 - Y_1)$, two additions. Makes the exceptional set symmetric: $(X_1{:}Z_1) \in \{(1{:}0),(0{:}1)\}$ produces $(0{:}0)$. Count trade: $+255\text{M}$ vs. one inversion by exponentiation ($\approx 254S + 11M$) — neutral; the gain is structural (no inversion in the hot path, composes with L12). Symmetry: same as L1. Surface: make `ladder` generic over the difference form. Script: `x25519_forms.sage` asserts `ladder_proj(k, (u*r, r)) == ladder(k, u)` for random $r \ne 0$.

### L3 `[adaptation]` — Hadamard coordinates $=$ Edwards $(Y{:}Z)$ ladder
Observe $(X_M{:}Z_M) = (Z_E + Y_E : Z_E - Y_E)$, hence $A = X_M + Z_M = 2Z_E$, $B = X_M - Z_M = 2Y_E$: the Hadamard pair of L1 *is* the Edwards $y$-line. State $(Y_2{:}Z_2) = y(R_0)$, $(Y_3{:}Z_3) = y(R_1)$, initial $(1{:}1), (y_1{:}1)$, constant $u_1 = (1+y_1)/(1-y_1)$:
$$AA = Z_2^2,\ BB = Y_2^2,\ E = AA - BB,\ U_4 = AA\cdot BB,\ W_4 = E(AA + a_{24}E),$$
$$DA = Y_3Z_2,\ CB = Z_3Y_2,\ U_5 = (DA+CB)^2,\ W_5 = u_1(DA-CB)^2,$$
$$(Y_4{:}Z_4) = (U_4 - W_4 : U_4 + W_4),\qquad (Y_5{:}Z_5) = (U_5 - W_5 : U_5 + W_5).$$
Count **5M + 4S + 1c + 8a** — the four input additions of L1 vanish and reappear as the four output additions, which are the Montgomery→Edwards map; net the ladder reads and writes Edwards $y$ with zero conversions. Checks: $(1{:}1)\mapsto(1{:}1)$; $T = (-1{:}1)\mapsto(1{:}1)$; the order-4 point $(0{:}1)$ gives $U_4 = 0$, $W_4 = 1 + a_{24}$, i.e. $(-1{:}1) = T$ ✓. Exceptions: $y_1 = \pm1$ (i.e. $P_1 \in E[2]$), exactly the $u_1 \in \{\infty, 0\}$ cases of L1. There is no point at infinity in this chart: $Z_E = 0 \iff u = -1$, which is a twist value and never arises from a curve point. Symmetry: $T$-translation is $Y \mapsto -Y$; the step depends on $Y_2$ only via $Y_2^2$ and on $(Y_2, Y_3)$ jointly via $(Y_3Z_2 \pm Z_3Y_2)^2$, so it is manifestly invariant. Constant-time as L1. Surface: `ed25519.rs` — the first uniform scalar multiplication for `EdPoint`; `encode()` needs $y$ (delivered directly) and the sign of $x$ (L4). Script: `x25519_forms.sage::hadamard_equals_rfc` asserts $(Z_4 + Y_4 : Z_4 - Y_4)$ equals L1's $(X_4{:}Z_4)$ projectively on 10³ random states.

### L4 `[adaptation]` — inversion-free Edwards $x$-recovery into extended coordinates
From the complete $a = -1$ law $y_3 = (y_1y_2 + x_1x_2)/(1 - d x_1x_2y_1y_2)$ with $P_3 = P_2 + P_1$, solve for $x_2$:
$$x_2 = \frac{y_3 - y_1y_2}{x_1\,(1 + d\,y_1y_2y_3)} .$$
Projective, from the final ladder state $(Y_2{:}Z_2) = y(kP_1)$, $(Y_3{:}Z_3) = y((k{+}1)P_1)$:
$$N = Y_3Z_2 - y_1\,Y_2Z_3,\qquad D_0 = Z_2Z_3 + (d\,y_1)\,Y_2Y_3,\qquad D = x_1 D_0,$$
$$kP_1 = (X{:}Y{:}Z{:}T) = (N Z_2 : Y_2 D : Z_2 D : N Y_2).$$
Count: $N$ 3M, $D_0$ 3M ($d y_1$ precomputed, 1M once per base), $D$ 1M, outputs 4M: **11M + 2a, 0 S, 0 I, 0 square roots**. Affine instead: invert $Z_2 D$ once (shared with the inversion the ladder needs anyway) — 5M + 1I. Completeness: $1 + d y_1y_2y_3 = (1 + d y_1^2y_2^2)/(1 - d x_1x_2y_1y_2)$; the numerator vanishes only if $(y_1y_2)^2 = -1/d$, a non-residue ($d$ non-square, $-1$ square), and the denominator is the complete-law denominator (BBJLP, $a$ square, $d$ non-square). Hence $D_0 \ne 0$ for **every** pair of curve points; $D = 0 \iff x_1 = 0 \iff P_1 \in E[2]$, already excluded by L3. Edge checks: $kP_1 = \mathcal O$ gives $y_3 = y_1$, $N = 0$, $x_2 = 0$ ✓; $(k{+}1)P_1 = \mathcal O$ gives $y_2 = y_1$, $y_3 = 1$, $x_2 = (1 - y_1^2)/(x_1(1 + dy_1^2)) = -x_1$ ✓ by the curve equation. If the slots are in the order $(R_1, R_0)$ the same formula returns $-x_2$ — the final select (L8) fixes the order. Symmetry used: the dual reading of the addition law (solve for a summand instead of the sum). This answers "obtain $y$ (here the missing Edwards $x$) from the final pair without a full inversion". Surface: `ed25519.rs` — feed `EdPoint::add` for $R + [k]A$ in verification with no inversion; `encode()` sign bit from $X$ after the one inversion signing already pays. Script: `x25519_forms.sage::edwards_recovery` asserts `E_W(map(x2,y2)) == k*E_W(map(P1))` for 10³ random $(k, P_1)$ and for $P_1$ of order 4, 8, $\ell$, $2\ell$, $4\ell$, $8\ell$, and asserts `not is_square(-1/d)`.

### L5 `[adaptation]` — Okeya–Sakurai projective $v$-recovery (Montgomery side)
Affine: $v_2 = \dfrac{(u_1u_2+1)(u_1+u_2+2A) - 2A - (u_1-u_2)^2u_3}{2v_1}$ (derived from the chord law; the term $x_3(u_1-u_2)^2 + 2v_1v_2 = (u_1+u_2)(1+u_1u_2) + 2Au_1u_2$). Projective, inputs $(u_1, v_1)$ affine, $(X_2{:}Z_2)$, $(X_3{:}Z_3)$:
$$t_1 = u_1Z_2,\ t_2 = X_2 + t_1,\ t_3 = (X_2 - t_1)^2 X_3,\ t_4 = 2A\,Z_2,\ t_2 \leftarrow (t_2 + t_4)(u_1X_2 + Z_2) - t_4Z_2,$$
$$Y' = t_2 Z_3 - t_3,\quad w = 2v_1\,Z_2Z_3,\quad X' = wX_2,\quad Z' = wZ_2 .$$
Count **10M + 1S + 1c + 7a** ($2A = 973324$). Exceptions: $v_1 = 0$ ($u_1 = 0$), $Z_2 = 0$, $Z_3 = 0$ — strictly more than L4, whose only exception is $x_1 = 0$. For $u_1 = u_2$ the formula returns $v_1$, correct iff $R_0 = P_1$; the other case $R_0 = -P_1$ forces $Z_3 = 0$ and is caught. X25519 proper cannot use it ($v_1$ is not on the wire; computing it needs a square root and fails on the twist); it serves Ed25519-derived keys and as an **on-curve self-check** of a ladder output: $Y'^2Z' \stackrel{?}{=} X'^3 + AX'^2Z' + X'Z'^2$ (4M + 3S + 1c). Surface: `x25519.rs` test-only fault check; `ed25519.rs` alternative to L4. Script: `x25519_forms.sage::os_recovery` asserts the curve identity on 10³ random outputs and asserts failure exactly on $\{v_1 = 0, Z_2 = 0, Z_3 = 0\}$.

### L6 `[known]` — co-Z Jacobian $(X{:}Y{:}Z)$ ladder carrying $y$ (dominated)
Move to short Weierstrass $x_W = u + A/3$, $y^2 = x_W^3 + a_Wx_W + b_W$, $a_W = 1 - A^2/3$, $b_W = A(2A^2-9)/27$ (the map filed in IDEA-20260807-e6d79e). Co-Z addition ZADDU of $P=(X_1,Y_1,Z)$, $Q=(X_2,Y_2,Z)$: $C = (X_1-X_2)^2$, $W_1 = X_1C$, $W_2 = X_2C$, $D = (Y_1-Y_2)^2$, $A_1 = Y_1(W_1-W_2)$, $X_3 = D - W_1 - W_2$, $Y_3 = (Y_1-Y_2)(W_1-X_3) - A_1$, $Z_3 = Z(X_1-X_2)$, returning $(P{+}Q, P) = ((X_3,Y_3,Z_3),(W_1,A_1,Z_3))$: 5M+2S. ZADDC adds $\bar X_3 = (Y_1+Y_2)^2 - W_1 - W_2$, $\bar Y_3 = (Y_1+Y_2)(W_1 - \bar X_3) - A_1$ for $P - Q$: 6M+3S. Ladder bit: ZADDC then ZADDU, **11M + 5S + 0c** per bit, $y$ carried throughout, no difference point. Exceptions: requires $R_0 \ne \pm R_1$ and neither at infinity, so it must start at $(P_1, 2P_1)$ and fails for $P_1 \in E[2]$ and whenever a prefix $k$ satisfies $kP_1 = \mathcal O$ or $(2k{+}1)P_1 = \mathcal{O}$ — it is less complete than L1. Verdict: $2.2\times$ the per-bit cost of L1 to carry $y$, versus 11M once via L4; dominated. Listed to close the "(X:Y:Z) carrying $y$" branch with counts. Script: `x25519_forms.sage::coz_matches` for 100 random $(k, P)$.

### L7 `[adaptation]` — shared denominator (co-Z on the $u$-line) $(X_2{:}X_3{:}Z)$
After L1 set $Z \leftarrow Z_4Z_5$, $X_2 \leftarrow X_4Z_5$, $X_3 \leftarrow X_5Z_4$: **8M + 4S + 1c + 8a**, state 3 elements. With common $Z$ the inputs are $A = X_2 + Z$, $B = X_2 - Z$, $C = X_3 + Z$, $D = X_3 - Z$ (no saving); a direct common-$Z$ derivation ($X_5 = Z_1(X_2X_3 - Z^2)^2$, $Z_5 = X_1Z^2(X_2-X_3)^2$) costs 8M+5S+1c and is worse. What it buys: the secret-dependent data movement shrinks to a single field element when combined with L8 ($X_s = X_2 + s(X_3 - X_2)$, one cmov). What it costs in completeness: the chart cannot hold $\{\mathcal O, P\}$; $Z_4Z_5 = 0$ when either $R_0$ or $R_1$ is $\mathcal O$ destroys both points. That happens at initialisation (start from $(P_1, 2P_1)$ instead), for all low-order $u$, and for any prefix $k$ with $\ell \mid k$ on a non-prime-order point — so it is strictly less complete than L1, and only accidentally RFC-compliant on low-order inputs (output $X_2\cdot\mathrm{inv}(0) = 0$). Honest delta: $+3M$/bit, $-1$ register, $-3$ masked elements/bit. Low priority; filed to show the count. Script: `x25519_forms.sage::coz_xz` asserts equality with L1 on random $(k,u)$ and asserts divergence on $u = 1$.

### L8 `[adaptation]` — select-not-swap ladder (the swap removed by arithmetic)
Keep the state as (doubled point, sum point) $= (X_D{:}Z_D), (X_S{:}Z_S)$ plus the previous bit $b'$ (initially $0$), initialised $(1{:}0), (u{:}1)$. For $t = 254,\dots,0$: $s = b_t \oplus b'$, $b' \leftarrow b_t$;
$$A = X_D + Z_D,\ B = X_D - Z_D,\ C = X_S + Z_S,\ D = X_S - Z_S,\qquad A_s = A + s\,(C - A),\ B_s = B + s\,(D - B),$$
$$AA = A_s^2,\ BB = B_s^2,\ E = AA - BB,\ X_D' = AA\cdot BB,\ Z_D' = E(AA + a_{24}E),$$
$$DA = D\cdot A,\ CB = C\cdot B,\ X_S' = (DA + CB)^2,\ Z_S' = u\,(DA - CB)^2 .$$
Output $R_0 = (X_D{:}Z_D)$ if $b_0 = 0$ else $(X_S{:}Z_S)$ — for clamped scalars $b_0 = 0$, no final select. Lemma: with $\{R_0, R_1\} = \{D, S\}$ ordered by $b'$, the next sum is $R_0 + R_1 = D + S$ regardless of order (the differential addition is symmetric: exchanging $(A,B) \leftrightarrow (C,D)$ maps $DA + CB \mapsto CB + DA$ and $(DA - CB)^2 \mapsto (CB - DA)^2$), and the point to double is $R_{b_t}$, which equals $D$ iff $b_t = b'$. Count **5M + 4S + 1c + 8a + 2 cmov** (masked: $A \oplus (m\wedge(A\oplus C))$, 3 word-ops per limb per element, 6 total) versus RFC's cswap of 4 elements (8 per limb): $-25\%$ masked traffic, zero change in M/S, no output placement. Exceptions identical to L1 (same multiset of points at every step). Constant-time: $s$ enters only as a multiplier/mask; every bit is read once; no branch. Symmetry: $S_2$ on the slot pair, realised by the symmetric differential addition. Surface: `x25519.rs::ladder` replacing `if s == 1 { swap }`. Script: `tests/ecc/ladder_forms.rs::select_equals_rfc` on 10⁴ random clamped and unclamped scalars.

### L9 `[known fact / adaptation as control]` — the $u \mapsto 1/u$ involution
Where it acts: translation by $T=(0,0)$. Chord slope $\lambda = v/u$ gives $u(P{+}T) = \lambda^2 - A - u = 1/u$, $v(P{+}T) = -v/u^2$; on $\mathbb{P}^1$ it is $(X{:}Z) \mapsto (Z{:}X)$; in Hadamard/Edwards coordinates it is $B \mapsto -B$, i.e. $Y_E \mapsto -Y_E$ (adding $(0,-1)$). On the step: swapping $X_i \leftrightarrow Z_i$ for both points negates $B$ and $D$, leaving $AA, BB, E, (DA{\pm}CB)^2$ unchanged, so $L(x_1; Z_2{:}X_2, Z_3{:}X_3) = L(x_1; X_2{:}Z_2, X_3{:}Z_3)$ as polynomials; equivalently $k(P{+}T) = kP + kT$. Consequences: $\mathrm{X25519}(k,u) = \mathrm{X25519}(k, u^{-1})$ for every even (hence every clamped) $k$ and every $u \ne 0$ (also on the twist, whose $(0,0)$ acts the same way); for odd $k$, $\mathrm{X25519}(k, u^{-1}) = \mathrm{X25519}(k,u)^{-1}$. The exceptional set is closed: $0 \leftrightarrow \infty$, $1 \mapsto 1$, $-1 \mapsto -1$, and the two order-8 $u$-values are the $\mathbb{F}_p$-roots of the palindromic quartic $u^4 - 4u^3 - (4A+2)u^2 - 4u + 1$ (from $u(2P) = 1$), swapped by the involution. What it saves: a differential-testing oracle needing no second implementation (one `fe_inv` per check) that catches any $X/Z$-asymmetric bug in cswap/select, doubling or reduction; halves the low-order inputs needing hand analysis; it saves nothing in M/S (the step is already a function on the involution's natural coordinates). Surface: `tests/ecc/ladder_forms.rs::inverse_u_invariance`; `x25519_checked` documentation (equivalent public keys $u$, $1/u$). Script assertion: `x25519(k,u) == x25519(k, inv(u))` on 10³ random clamped $k$ and all low-order $u \ne 0$.

### L10 `[adaptation]` — the quotient ladder is the 2-isogenous curve, and its constant is full-size
The $T$-invariant coordinate $X' = u + 1/u$ is Vélu's 2-isogeny $\phi: E \to E'$, $E': Y^2 = (X'+A)(X'-2)(X'+2)$; the dual on the $u$-line is $\hat\phi(X') = (X'^2-4)/(4(X'+A))$ and $\hat\phi\circ\phi = [2]$ ($(u+1/u)^2 - 4 = (u^2-1)^2/u^2$, $4(u + A + 1/u) = 4(u^2+Au+1)/u$). Since $E(\mathbb{F}_p)[2] = \{\mathcal O, T\}$ this is the only rational 2-isogeny from $E$. $E'$ has full rational 2-torsion; Montgomery form needs a 2-torsion root shifted to $0$ with square $a_4$: shifts give $a_4 \in \{4(A+2),\ -4(A-2),\ A^2-4\}$ and only $4(A+2)$ is a square, so the Montgomery model is unique up to sign: $\xi = (X'-2)/(2\sqrt{A+2}) = (u-1)^2/(2\sqrt{A+2}\,u)$, $B'y^2 = \xi^3 + A'\xi^2 + \xi$, $A' = (A+6)/(2\sqrt{A+2})$. Projectively $\phi: (X{:}Z) \mapsto ((X-Z)^2 : 2\sqrt{A+2}\,XZ)$ (1M+1S+1c). For even $k$: $\mathrm{X25519}(k,u) = \hat\phi\big([k/2]\,\phi(u)\big)$, a 254-step ladder on $E'$ with $(A'{+}2)/4$ a full-size constant: **$254\cdot(6M+4S) + 4M + 1S + 2c$ versus $255\cdot(5M+4S+1c)$**, i.e. $\approx +250\,(M - c)$: a loss of roughly one fifth. Closed negative: no Montgomery curve one rational 2-isogeny away from $E$ has a small $a_{24}$; the small-constant advantage belongs to the representative $E$ alone. Positive use: an independent second computation path (different curve, different constant, 254 steps) for differential testing of `ladder`. Script: `x25519_forms.sage::two_isogeny` asserts $\hat\phi(\phi(u)) = u(2P)$, asserts `legendre(-4*(A-2)) == -1 and legendre(A^2-4) == -1`, asserts `min(A', p-A').nbits() > 200`, and asserts the identity on 10³ random clamped $(k,u)$.

### L11 `[adaptation]` — specialise the four public bits of a clamped scalar; fixed base $u=9$
Clamping fixes $b_{254} = 1$ and $b_0 = b_1 = b_2 = 0$; these bits are public, so specialising them leaks nothing. Initialise $(R_0,R_1) = ((u{:}1), 2(u{:}1))$ with the affine doubling $AA = (u+1)^2$, $BB = (u-1)^2$, $E = AA - BB$, $X = AA\cdot BB$, $Z = E(AA + a_{24}E)$ (2M+2S+1c); run 251 full steps for bits $253\ldots3$; resolve the pending swap/select by $b_3$ once; then three pure doublings ($2M+2S+1c$ each) of $R_0$ for bits $2,1,0$. Total **$251(5M+4S+1c) + 4(2M+2S+1c) = 1263M + 1012S + 255c$** versus $1275M + 1020S + 255c$: $-12M - 8S$ and $-4$ masked swaps. For `x25519_base` ($u_B = 9$, also the Edwards base $y = 4/5 \mapsto u = 9$): $Z_5 = 9(DA-CB)^2 = 8t + t$ (three field doublings and one add), so each full step is **4M + 4S + 2c**: $1012M + 1012S + 251c_9 + 255c$. Not applicable to unclamped Ed25519 verification scalars. Surface: `x25519.rs::ladder`, `x25519_base`. Script: `tests/ecc/ladder_forms.rs::specialised_equals_rfc` (10⁴ clamped scalars; RFC vectors).

### L12 `[known]` — batched final inversion for `ecbench`
For $n$ ladder outputs $(X_i{:}Z_i)$: $c_i = \prod_{j\le i}Z_j$, $t = c_n^{-1}$, $Z_i^{-1} = t\,c_{i-1}\prod_{j>i}Z_j$ by back-substitution: **$3(n-1)M + 1I$** versus $nI$. A zero $Z_i$ poisons the batch; mask it constant-time: $Z_i' = Z_i + [Z_i = 0]$ and force output $0$ for flagged entries, matching RFC 7748's all-zero result. Surface: `ecbench` repeated-scalar-multiplication driver. Script: assert batched outputs equal per-call `x25519` on a batch containing $u = 0$ and $u = 1$.

### L13 `[known]` — fixed-radix field layer (prerequisite for every constant-time statement above)
