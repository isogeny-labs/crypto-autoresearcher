# Separate blockwise exporter controls

`quotient_lift_batched.cpp` preserves the closure algorithm, quotient coordinates and on-disk certificate format, but computes the final linear projection in blocks of at most4096 rows using M4RI matrix multiplication. It does not replace the binary or source pinned by the active fifty-input frontier protocol.

Three generic Boolean controls produced byte-identical certificates against the original native exporter and passed independent closure conditions. The sixteen-variable fixture crosses the4096-row boundary, has a partial final block and a non-word-aligned quotient dimension; see `batched-export-controls.json`. Three Semaev cascades additionally passed all nine original-checker stages and direct dense codimension comparisons. Their stage certificates are byte-identical to the original cascade controls; see `cascade-batched-20261029/reference-comparison.json`.

These controls establish tested output equivalence, not a measured speedup, frontier feasibility or a new fall-degree bound. The existing conservative allocation envelope and external address-space limit are retained. Any scientific use requires a separate pinned instrument and frozen protocol; the current attempt remains unchanged.
