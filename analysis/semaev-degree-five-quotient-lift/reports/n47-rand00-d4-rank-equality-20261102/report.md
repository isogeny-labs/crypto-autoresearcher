# n=47 random00: exact degree-four closure equals the accepted quotient kernel

The independent implementation B replay computed the exact degree-four Boolean closure rank **151,857** in an ambient space of **213,053** monomials, with the constant absent. The previously accepted D4 quotient has 61,196 coordinates, so its kernel also has dimension `213053 - 61196 = 151857`. The original checker established `W_4(F) ⊆ U_4` for this same certificate and input. Equal dimensions therefore establish **`W_4(F) = U_4` for the named n=47 random00 presentation**. This is a finite-instance, independently replayed equality; it is not an asymptotic statement or an exact LFD claim.
