# Streamed D5 certificate custody qualification

The bounded exporter, AWS CLI stream upload, full S3 download, and original independent checker completed one native small-system control without a local output certificate. The downloaded bytes were hashed while being fed to the checker. The 1,040-byte certificate SHA-256 was `7cf2d46d96fe00dfddd1277935c7f0b6577c7ab9cbdc774151c81f56fee82d73`, matching the fixture's frozen expected hash; the checker accepted `1 ∉ W_5(F)` with codimension at least 3. The [run receipt](evidence/result.json), [checker transcript](evidence/checker.stdout.txt), and [request](evidence/plan-s3-v4.json) retain the exact identities. The object is at `s3://setec-astronomy-artifacts/validation/semaev-d5-stream-custody-20261101/d5/native-fixture-0-s3-v4.candidate.bin`.

The [transport](../../stream_certificate_custody.py) checks producer, checker, and input SHA-256 identities before launch. It refuses an existing object, caps streamed bytes and time, requires producer success and a candidate status, verifies stored length, hashes the full S3 readback, and requires the independent checker to reproduce the D5 codimension. A partial or changed stream has no accepted result. Four local adversarial tests cover successful transfer, changed input, changed readback, and producer failure. The [diagram](pipeline.svg) shows the checked path. The native control used the previously qualified bounded exporter binary SHA-256 `9cd484197ed9afb3eeb4466b06e143b440b2ec47a133a6d5433a8f2eaa5b5797` and original checker SHA-256 `b6e28168091986b3cb04790f51889723db0ec5838633767bb80a6dc4ac97bd70`; the transport source SHA-256 is `0dfad8bf3bfbaf463ade9e9d96a32bd647910a2ab5c9028637390eb2a560130f`.

This is a 1,040-byte storage and checker qualification, not a high-memory n51 D5 trial. The n51 trial still needs a frozen request that binds the 1.68 GB D4 seed, actual pod image and memory cap, timeout, exact count, output ceiling, and the same readback/checker path. The 96 GiB pod capacity probe and read-only n51 profile are in the [n51 publication PR](https://github.com/isogeny-labs/crypto-autoresearcher/pull/2918); no degree-six lower bound follows from this transport test.
