# Independent full-row verification of the n50 sliced D4 rebase

The independently written [checker](verify_rebase_kernel_equivalence.py) verified that the two retained 49-variable D4 maps have **the same kernel**. It rehashed both raw 1,120,585,872-byte files, read literal unit representatives from the *output* map, selected the corresponding *input* rows, and proved those input rows form a basis. It then applied the uniquely determined invertible change of codomain basis to every one of the 231,526 input rows and compared each result with the output row. This does not replay the producer's reverse-greedy pivot arrays.

The selected basis has 37,687 unchanged unit coordinates and 942 changed coordinates. The 942 input projections on the changed coordinates have rank 942. All 231,526 row comparisons passed. Therefore the sliced map before and after rebase has the same kernel, independently of the fast rebase implementation's source-level argument.
