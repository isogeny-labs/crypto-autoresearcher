# Shared implementation interface

Root owns src/common.hpp and fixture generation. Module authors own only assigned module files. C++20, standard library plus header-only Boost where already available. No Python cryptographic calculations. Each module is a standalone executable, accepts `--self-test` or `--run FIXTURES_TSV OUTPUT_JSONL`. Root performs scientific/pilot execution only after source and protocol freeze; module authors run development checks only. Do not claim official admission, novelty, solver performance or a new algorithm.

common.hpp namespace lab:
`using I = std::int64_t; struct Point { I x,y; bool inf; ==; }; struct Curve { I p,a,b; I mod(I) const; I pow(I,I) const; I inv(I) const; bool valid(Point) const; Point neg(Point) const; Point add(Point,Point) const; Point mul(Point,std::uint64_t) const; std::vector<Point> points() const; }; struct Fixture { std::string id,stratum; Curve c; Point P; I r,N; std::uint64_t seed; }; std::vector<Fixture> read_fixtures(const std::string&); void certify(const Fixture&); std::vector<Point> orbit(const Fixture&); struct RNG { explicit RNG(std::uint64_t); std::uint64_t next(); void shuffle(std::vector<I>&); }; bool prime(I); unsigned bits(std::uint64_t); void require(bool,const std::string&); std::string json_quote(const std::string&);`

Point infinity is `{0,0,true}`, ordinary point `{x,y,false}`. Orbit array index k is [k]P, only for explicitly enumerative observational/reference computations; charge its construction, never call it a fast decoder. `r` is odd prime. `p <= 65535`. Affine multiplication/point enumeration are reference operations, not constant time. Every emitted row includes track, fixture id, scope="exploratory_toy_diagnostic", actual counters and outcomes. Throwing must exit nonzero; preserve no partial success interpretation. Root archives stderr and all attempts. Avoid giant raw pair tables; report exact histogram aggregates plus digests if applicable. Maximum one process per module; no nested threads.

Initial additive pilot: ordinary non-anomalous non-special-j main curves at subgroup bit lengths 5,6,8, two each; two separate j=0 automorphism fixtures at 6 bits. Exact generated manifest registered locally with certificates before measurement. This pilot is smaller than the earlier proposed 8/10/12 discovery cohort and does not replace its acceptance criteria or the held-out solver study. No hard constructor is assumed; a control-only module states its remaining construction gap.
