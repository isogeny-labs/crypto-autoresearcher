# Fixed-circuit transfer engine

This is preparation source for EXP-ECDLP-ef7323 / RUN-ECDLP-ea5986, not a record of scientific execution. A committed source closure, frozen standalone/official protocol, lawful ownership, admission and checkpoint precede the one actual isolated invocation. `--plan-only` performs no cohort draw, entropy call, legacy control, constructor preparation or evaluator call.

The two fixed recipes are `(alpha,beta)=(1,-4),(-2,-1)`, with known base multipliers `a=1,2,3,5`. For each public nonidentity target `Q`, each arm draws four independently domain-separated `b` values uniformly in the nonzero scalar field, computes `Q_b=[b]Q`, and uses `P'=[a]P`. Exactly `L=bit_length(r)+1` fresh predicate evaluations are made for every attempt, including after an undefined value. Their binary interval must contain an integer `x'<r`; an empty interval is rejected without reduction modulo r. A candidate is converted by `x=a*b^-1*x' mod r` and both `[x']P'=Q_b` and `[x]P=Q` are checked. The scalar-field inverse, blinding multiplication, known-base transformation, predicate work, conversion and final checks have separate operation vectors.

For fixed `P,a` and a prime-order group, uniform nonzero `b` makes `bQ` uniform over the nonidentity subgroup for any fixed nonidentity `Q`. Repeating with a fresh b is therefore a genuine randomized retry, unlike rerunning an unchanged deterministic circuit on the same Q. The source records success counts without declaring an asymptotic advantage. Cold retry accounting is `S+E[C]/q` (setup reused); observed batch accounting is `(S+sum C)/verified_successes`, vector by vector. A zero-success sample gives an undefined empirical ratio, not a proof of q=0. No arbitrary price combines field, group, scalar, RNG or dictionary counters.

There are eight fixed candidate arms, one exact A/A replay of `circuit1.a1` sharing its b stream, four independent uniform scalar candidates per Q, and one actual working additive baby-step/giant-step solve per Q. The BSGS baby table is built once per fixture and its setup is charged once; neither it nor any scalar label is supplied to a constructor. BSGS and uniform references are not copied into new observations per candidate arm. All candidate/AA attempts execute before the baseline table is constructed. The source uses the same affine operation API for candidates and reference; it does not mix Python API counts with the earlier native binary's counters.

The planned fresh cohort has 40 distinct ordinary prime-order curves and 2,512 nonidentity target IDs. It yields 80,384 fixed-candidate attempts, 10,048 A/A attempts, 10,048 uniform candidates and 2,512 BSGS solves: 102,992 primary rows. The exact small strata use r=17,31,61,127 (two curves each); larger strata use 16 curves at each 10- and 13-bit subgroup order with 64 distinct public-coordinate targets each. An unblinded all-r bit diagnostic (including O) runs only on the eight small curves, after all primary attempts; its 3,776 predicate records never gate primary execution. All failures and undefined values remain recorded.

The fresh cohort generator owns its nonce, proposal history, complete point census/certification, geometric exclusions, public coordinate sampling and costs. Its nonce is written and fsynced before any fresh draw, and no scalar truth file is produced. The engine stops without any primary attempt if generation is incomplete. Complete primary inputs are validated separately: primality/nonsingularity, base r-torsion, point membership and nonidentity target checks. Full curve-order certification is independently assessed by the verifier. Input construction/common validation are observed once and retained separately; a full per-arm workload comparison must explicitly allocate the same common cost rather than pretending those were new repeated executions.

A fixed previously observed F11 control runs inside the admitted actual invocation before the fresh nonce: P=(2,7), Q=(7,2), a=5, b=1 and circuit1 recover x'=4, x=7 in five fresh calls; BSGS returns7 and wrong scalar8 is rejected. These two control attempts and the negative equation check are a separate phase and do not inflate the fresh-cohort counts. A control failure is an operational/integrity issue and aborts fresh generation.

Raw outputs include `attempt-intents.jsonl`, `attempts.jsonl`, `setups.jsonl`, `diagnostics.jsonl`, the complete `cohort/` tree, `control-phase.json`, `compute-summary.json` and `completion.json`. Every attempt has a flushed intent before work and a flushed completed record afterwards. An intended-but-unrecorded attempt after interruption is unresolved; remaining planned IDs are unattempted. Partial trailing bytes are retained. A retry is never automatic. Compact query traces retain target coordinates and full answers; per-attempt evaluator vectors are exact sums, while per-query vector copies are omitted. The independent verifier does not independently replay candidate counter increments.

Python container/control work, source/provenance checks, JSON/hash/file I/O and the bit cost of each arithmetic operation are not exhaustively priced. Counters are source-defined diagnostics; all clocks remain unqualified. The earlier `constructor.conditional_recover` is preserved as prior reusable source but is not the primary transfer path: `compute.ungated_attempt` supplies the fixed-L, blinded, strict-interval semantics.
