Independent public verifier for endpoint recycling

This directory contains development software, not results of the prospective
64-curve study. The verifier imports only Python's standard library and does
not call the producer's arithmetic or consume secret scalar labels.

Interface:
  python3 -B verification/verify_public.py \
    --fixtures public/fixtures.tsv --targets public/targets.tsv \
    --settings public/settings.tsv \
    --records raw/static_small.jsonl --records raw/static_full.jsonl \
    --records raw/static_filled.jsonl \
    --records raw/harvest.jsonl --records raw/harvest_disabled.jsonl \
    --records raw/rho_reference.jsonl \
    --expect-arm static_small --expect-arm static_full --expect-arm static_filled \
    --expect-arm harvest \
    --expect-arm harvest_disabled --expect-arm rho_reference \
    --out FRESH_VERIFICATION_DIRECTORY

Repeat --records for every complete JSONL stream. Parts must end at complete
JSON rows; byte-split storage parts must first be reconstructed losslessly.
The output directory must not exist. summary.json is a machine-readable
verdict; cases.jsonl retains one row per completed recorded target/arm case.

Exit codes:
  0: all supplied public equations, observed state transitions and requested
     target/arm coverage pass.
  1: an input, equation, transition, stream, or coverage requirement fails.
  2: verification could not start, including refusal to overwrite output.

Checks:
  * Exact primality by trial division in the declared p<2^20, r<2^19 domain;
    nonsingular short Weierstrass curve, nonzero P, and [r]P=identity.
  * Public total-order assertion lies in Hasse's interval and is divisible
    by r. This is NOT an independent count of the whole curve. The stronger
    inequality Hasse_upper<r^2 rules out independent rational r-torsion, so
    on-curve targets annihilated by r lie in the subgroup generated by P.
  * Every initial known exponent e labels its endpoint [e]P; the public full
    point hash and distinguished-point mask agree. Exponents are canonical,
    unique and the known prefix is sorted.
  * The cell ID, DP rule, setup/online limits, common setup seed, requested
    build size, thread count and walk count match public settings.
  * A failed terminal satisfies D=Q+[a]P. Only distinguished terminals can
    enter the pending tail, and known+pending never exceeds the declared
    endpoint arena capacity.
  * Observed lookup ranges and witness indexes search only the already-known
    prefix. Candidate witnesses and their verification flags are recomputed.
    An unmatched endpoint cannot skip a valid known-bucket witness.
  * A public scalar verification event [x]P=Q precedes every promotion; its
    new label is e=(x+a) mod r and [e]P=D. Exact canonical exponent equality
    determines duplicate rejection. Commit intent does not activate entries;
    activation occurs only at a successful final target row. Unsuccessful
    targets discard all staged entries and retain their producer status.
  * Static and rho witnesses also satisfy [x]P=Q. All requested public
    target/arm cases are present exactly once, including repeated Q values.
    A ready static_filled setup must contain exactly C distinct known endpoints.
    A static_full setup instead requests C upstream chains and may contain
    fewer entries after deduplication; its observed occupancy remains explicit.

Summary semantics:
  schema: classical.ecdlp.endpoint-reuse.public-verification.v1
  status: public_equations_and_trace_pass | invalid_public_record
  verified_case_witnesses counts final target scalar witnesses only, excluding
  terminal, proposal and lookup-candidate equation checks. Producer failure,
  censoring and invalid statuses are retained and are not automatically a
  malformed-record error. Missing rows or malformed/wrong equations are errors.
  input_sha256 maps each exact supplied path to its byte SHA-256; the verifier
  source is bound separately by verifier_sha256.

Trust boundary:
  These checks validate the supplied public records against equations and a
  state machine. They do not attest that the producer actually executed every
  recorded operation, that an omitted operation never happened, or that the
  host was isolated. Native cost counters are not independently replayed.
  A self-consistent fabricated trace could pass; execution/source/artifact
  admission and independent scientific review remain separate obligations.
  The order-independent XOR table_state_hash64 is an audit checksum, not a
  cryptographic commitment. Complete entry witnesses and input-file SHA-256
  bindings provide the checks used here.

Development checks:
  python3 -B -m unittest -v test_verify_public
  The tests use fixed public hand fixtures and intentional mutations. They
  are software conformance checks, not fresh-cohort measurements or a claim
  of improvement over Bernstein-Lange, rho, or any other algorithm.
