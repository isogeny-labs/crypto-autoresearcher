## Problem

The P29/P37 graph now has 2,304 checked degree-7 edges and 2,306 vertices, but the requested comparison of relation yield, useful rank, and minimum/maximum complete same-point ECDLP cost cannot yet be established. Source-base transport has been independently replayed through all 2,048 P29 edges and all 256 P37 edges. Exact targetwise ordered-count equality passed on 128 fixed public control targets at P29 index 8 and P37 indices 4, 24, and 256. The graph-wide run still lacks equality on the committed discovery stream, a frozen admitted collector schedule over the fixed vertices and bases, and a complete index-calculus solve and matched-cost pipeline. The existing exact triple collector measures mathematical availability on prepared inputs; that alone does not time relation solving or recover an unknown scalar through the full pipeline.

The prospective design fixes three main bases on every vertex, additional prespecified check arms, discovery and fresh confirmation targets, finalist selection, and full cost accounting. It remains a draft rather than an approved `EXP-*` contract. The [candidate schedule](../research/isogeny_relation_yield_scan_20261016/graph_schedule_20261023/report.md) specifies 8,206 discovery arms with explicit full quotas and four check controls per scheduled check vertex, including separate coordinate-native and coordinate-transported arms. This resolves the planning ambiguity in a reviewable candidate artifact; it does not approve or execute the schedule. The first 20-arm conductor-step study remains a distinct frozen experiment.

The graph-transported source base is now an implemented check-vertex arm, and a write-once graph-specific wrapper can execute independent prepared-input, collector, ordered-count, and rank phases. Fixed public P29 source/check controls passed targetwise and bytewise equality on 128 targets, including five nonempty targets and five verified rank increments. This removes the missing *component wiring* for that bounded control. The candidate discovery schedule now specifies every check-arm quota; it is still not admitted or run. Candidate confirmation intervals, paired targetwise summaries, and a bounded modular solver control exist, but no complete same-point ECDLP-cost pipeline has run.

The finalist preparation path now binds public source G,Q points in the custodian manifest, and a rootless transfer runner maps that pair through a saved path with independent Sage replay. A P37 vertex-24 implementation control passed over 24 edges; its report separates map setup, point evaluation, validation, and process wall time. The candidate solve-plan compiler now checks shared source points and a common ordered target-vector digest across all finalists within a stratum. Focused tests pass. These additions remain uncommitted implementation/control work and provide no graph-wide relation-yield, rank, or solve-time observation.
