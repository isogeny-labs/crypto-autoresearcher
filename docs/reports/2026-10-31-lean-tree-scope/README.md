## Reproduce

The three gzip-compressed JSON inventories were generated by `crypto/tools/formal_coverage_inventory.py` at the frozen crypto commit, run once in each repository with the exact commit in `manifest.json`. The outputs were compressed with `gzip -n -9`, retaining their uncompressed SHA-256 hashes and recording each compressed archive hash. The script counts every tracked `.lean` path and lexical theorem/lemma line, including inactive and self-test sources; it does not build Lean. `manifest.json` records the script hash, exact source trees, inventory hashes and the full cryptanalysis path partition.

```sh
python3.11 verify.py --crypto-repo /path/to/crypto --cryptanalysis-repo /path/to/cryptanalysis --auto-researcher-repo /path/to/crypto-autoresearcher
python3.11 render.py
rsvg-convert -f pdf -o report.pdf scope.svg
```

`verify.py` reads only the named local Git objects, disables Git transports, and fails if any frozen Lean path/blob map, inventory digest, receipt hash or partition changes. It does not authenticate an old CI run or evaluate theorem meaning. The diagram is generated from `manifest.json`; no performance value or scientific comparison is inferred. The exact-object verifier passed on the three local repositories under optimized Python (`-O`). A negative control deleting one outside-receipt path from a copy of `manifest.json` exited 1 under the same optimized mode with `manifest differs from exact Git recomputation` (`negative-control.txt`).
