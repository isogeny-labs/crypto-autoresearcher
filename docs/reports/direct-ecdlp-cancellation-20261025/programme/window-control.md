# Exact scalar-window control for the direct classical programme

Derived argument and developer regression check, 2026-10-25. This is a known
fixed-window control, not a novel ECDLP algorithm, admitted experiment, or
performance result. The two files in this note are `window-control.cpp` and
this source. No scientific ledger status is changed.

## Object and domain

Let the subgroup be cyclic of odd prime order r, and let d >= 1 and m=2^d.
The familiar window update is A -> [m]A + [b]P, 0 <= b < m. After a
mathematical relabeling of all subgroup elements by their scalar in Z/rZ,
its full boundary matrix is

    M_d[A,B] = sum_{0 <= b < m} 1[B = m A + b mod r]  in F_2.

Repeated outputs when m > r are included with multiplicity and XOR. Choosing
scalar labels is legitimate for proving a rank invariant, and supplies no
procedure for finding the scalar label of a supplied target. The C++ check
uses these known scalar labels deliberately; it is not an EC inversion test.

For local tags, put

    R_d = F_2[eps_0,...,eps_{d-1}]/(eps_i eps_j for all i,j)
    T_d[A,B] = sum_{b=0}^{m-1} 1[B = m A + b mod r]
                                  (1 + sum_j bit_j(b) eps_j).

The constant coefficient of T_d is M_d. These are local window-bit tags;
incoming prefix tags, a pinned target, and a composition rule would be
additional data, not assumptions of this control.

## Derived rank identity

**Claim:** rank over F_2 of M_d is exactly r-1.

1. Multiplication by m permutes Z/rZ because gcd(m,r)=1. Thus its rows,
   reordered, are all cyclic shifts of the coefficient vector of
   W_d(x)=1+x+...+x^(m-1), reduced modulo f(x)=x^r-1.
2. Their span is the ideal generated by W_d in F_2[x]/(f). Multiplication
   by W_d on this r-dimensional vector space has rank
   r - deg(gcd(W_d,f)). For completeness, writing g=gcd(W_d,f), the
   polynomial divisibility f | W_d h is equivalent to f/g | h. Its kernel
   therefore has dimension deg(g), represented by multiples of f/g of
   degree less than r.
3. In characteristic two, x^m-1=(x-1)^m because m is a power of two.
   Consequently W_d=(x-1)^(m-1). As r is odd, f has a simple root at 1:
   f'(x)=x^(r-1), coprime to f. Therefore gcd(W_d,f)=x-1, proving the claim.

The proof in fact holds for every odd integer r>1. The registered regression
fixtures use only the requested six odd primes. It does not need primality
of the field characteristic or any specific elliptic curve equation.

**Interpretation boundary:** an exact sum of q rank-one outer products for
this *full point-state flattening* needs q >= r-1. This does not lower-bound
the time of arbitrary bit-coordinate computation or target-conditioned
contraction. Even the identity matrix has full rank and a cheap description.
The matrix here already has a short sum-of-shifts description when d is
fixed. A large global matrix rank is thus a diagnostic against one particular
low-rank representation, not a reason to close the direct-scalar programme.
No assertion about a notion of matrix rank over the non-field ring R_d is
needed or made.

## Exact tagged margins

For every fixed input A, summing T_d[A,B] over all B counts each b exactly
once. For every fixed output B, summing over A also counts each b exactly
once, since m is invertible modulo r. Both margins are therefore

    sum_{b=0}^{2^d-1} (1 + sum_j bit_j(b) eps_j)
      = eps_0  if d=1,
      = 0      if d>=2.

The constant coefficient is zero for every d>=1. Each bit occurs exactly
2^(d-1) times, explaining the two cases. For a one-bit window located at
global bit position j, the nonzero margin is eps_j instead. In particular,
untagged cancellation does not automatically preserve the tagged response:
the d=1 tagged margin is nonzero even though its constant coefficient is
zero. At d>=2 these *unpinned* margins vanish in every coefficient; this
alone says nothing about the nonzero target-pinned unique-preimage response.

## Developer regression evidence

The fixed test domain is r in {3,5,7,11,13,17}, d in {1,2,3,4}. The code
constructs each tiny matrix by explicit branch enumeration, extracts the
constant part, and computes its rank by ordinary binary Gaussian elimination.
It also verifies every tagged row and column margin. A deliberately flipped
constant coefficient must be detected by a margin check. Identity, zero, and
all-ones matrices calibrate the rank routine separately.

## Next use in an experiment contract

Use this window as an expected-obstruction control for a proposal claiming
small full-boundary rank, and as a tagged-semantics control for a compiler.
A correct implementation must reproduce the formulae above before a local
rank observation is interpreted. A candidate EC-specific identity must state
its exact boundary object and why it is not merely this known window update.
For a target-local representation, neither success nor failure of this
global control settles construction cost, compositional soundness, or ECDLP
solver scaling. Those remain separate, presently unsupplied obligations.
