### Part 1 findings (none changes the verdict)

* P1 (documentation, protocol vs script). `arms.null.parameters.draws = 40` in the frozen protocol, but the hash-bound script uses DRAWS = 200 and `sample_size.replicates`, `metrics` and README all say 200. The variable ledger still says "I3 at 10 only" (no I3 here) and lists curve_class levels A-D without E. Stale text carried from WEAKCLASS; the executed code and decision rule are unambiguous.
* P2 (reproducibility binding). `measurement.record` declares python_version, numpy_version and script_sha256, but none appear in rows.jsonl, run.log or verdict.json. No dirty-tree or commit stamp for the run. No `experiment.export/v1` bundle (other studies in this program have one). The values reproduce bit-exactly in my environment, so this is a record gap, not a result risk.
* P3. `freeze.commit` is `0e99eb1b`, the draft commit whose protocol.json still says status draft. The frozen file first appears at `948ab2d0` (one second later). The hash binding is sound (body identical). "Filed before data" rests on commit chronology (freeze 16:35:22, data commit 16:40:56), which the artifacts cannot prove beyond that.
* P4 (wording). README says D and E come from "the same acceptance conditions". D additionally requires `n not in used` at that p, and D primes are restricted to primes that host a weak partner (anomalous exists, small-k target exists, p = 1 mod 3), whereas E primes are uniform. D rows use 71 distinct primes (E: 108). This does not bias u (the null is per curve and n-matched), but the MWU independence assumption is slightly optimistic for D.
* P5 (precision of "closed as chance"). 95% CI for mean u(D) - mean u(E) is [-0.061, +0.090]. That excludes the original -0.25 shift and anything below about -0.06, but the study has about 50% power only for a 0.10 shift at alpha 0.01 (the protocol states ~45%). "Closed" should read "an effect of the original size is excluded".
* P6 (overreach). README sentence "there is no shift for anomalous or small-embedding-degree curves" and the rows' "no shift" claim more than "no detection". Class A or B versus E has SE 0.056; minimum detectable shift at the Bonferroni level is about 0.13 (50% power) and 0.18 (80% power). The row-level "does not detect" is correct; "no shift" is not supported.
* P7 (mechanism not tested in-study). README states that the class-C effect "reflects how the factor base is built" (zeta-closure leaves fewer independent frequencies). The study has no control arm for this (the null is negation-closed only). My supplementary check (not part of the frozen protocol; `val/lambda_null.py`, 200 draws per curve, own rng seed): confirmed that all 36 C factor bases are closed under negation and multiplication by lambda; against a lambda-and-negation-closed null the mean u of the 36 C curves moves from 0.233 to 0.431. So the symmetry explanation accounts for most of the shift but not all, and the lambda-closed null itself looks overdispersed (many u near 0 and near 1). Treat the mechanism as supported in direction, not established.
* Also verified: D partners per class 0.546 (A), 0.505 (B), 0.456 (C); pick-seed means 0.55, 0.39, 0.53, 0.54 (seed 1 is 1.9 SE low, unremarkable among four).
