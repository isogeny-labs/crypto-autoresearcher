# Blind algebra card: polynomial Frobenius reduction

Work only from this card. Do not read repository files, Git history, prior
reports, proof code, receipts, or other reviewers' output. Record every source
you read and seal your result before any comparison.

Let `p` be prime, `e` a natural number, `q = p^e`, and `K` a commutative ring of
characteristic `p`. Let `R = K[x_1,...,x_M]`, including the cases `M = 0` and
`e = 0`. Let `I_q` be the ideal generated by `x_i^q - x_i`. Define `phi` on `K`
by `a -> a^q` and apply it coefficientwise to `g in R` to obtain `g^phi`.

Independently determine whether `g^q - g^phi` belongs to `I_q` for every `g`.
Derive both the algebraic reason and an explicit finite test case, without
assuming any statement about solving degree or a particular Semaev system.

Attack the following nearby claims, giving a worked witness for each:

1. Can the ideal be omitted, so that `g^q = g^phi` holds as a literal
   polynomial equality? Use `K = F_2`, `q = 2`, and `g = x`.
2. Can `q` be changed to `3` while `K` has characteristic `2`? Use
   `g = x + y` and the ideal generated by `x^3-x` and `y^3-y`; determine the
   residue of `g^3-g^phi` and whether it vanishes.
3. Check a non-prime-field coefficient: `K = F_4 = F_2[a]/(a^2+a+1)`,
   `q = 2`, and `g = a*x + 1`.
4. Check the empty-variable and `e = 0` cases directly.

Return a report, a `review_attestation.yaml` with the task ID and joint name
specified in the handoff, and SHA-256 hashes of every output. Do not state a
verdict about the producer's Lean code or an archived run; this is a blind
mathematical derivation only.
