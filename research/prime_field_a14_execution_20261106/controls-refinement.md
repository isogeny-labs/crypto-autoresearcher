## Assessment and ranking

**Accept and rank the source-free known48 control as part of this same bounded
comparison.** Hybrid norm32+helper16 has up to 48 geometric atoms, whereas the
original known32 comparator has 32. The larger atom set changes the available
signed triples and pair table, independent of whether retaining unknown norm
structure is useful. A hybrid advantage over known32 alone could therefore be
explained by using 16 more atoms. It would not discriminate the stated mechanism.

Paid known48 tests a concrete alternative: supply public labels for a base of
the same nominal size, skip source learning and directly recover target
functionals. Keep known32 as well: it is the implemented A13 control and
exposes the cost/coverage change from buying 16 more known atoms. Norm32 remains
the component reference for gains on its original unknown columns. The four
programs answer different parts of the same question, rather than adding an
unrelated lead or another larger-field transfer.

Equal cardinality is not equal geometry, public knowledge or constructor work.
Known48 is therefore a necessary strong control for an atom-count explanation,
not proof that all confounding is removed or that it is globally optimal. A
hybrid benefit must be reported against both known32 and known48 exact target
identities and included cold costs. No favorable outcome, known48 dominance
or helper benefit is assumed.
