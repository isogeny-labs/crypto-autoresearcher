# Producer proof sketch (withheld from blind soundness reviewer)

Conservative extension: for any canonical old field/root assignment let S=-u-ht modp and E=j+(h-1)tu+binom(h,2)t² modp. They have canonical bit representations, and deterministic product range states satisfy their added range equations. The old state-bit map preserves all original constraints. Forgetting the two fields/state blocks recovers the original root. Projection is unchanged because both fields are auxiliary. Merely adding bits without those linear equations would not establish any relation to source coefficients.

Moment premise: evaluate the source interval idempotents and nilpotent N at any support root in an algebraic closure. Idempotents give0/1; nilpotence forces each root to t plus an integer offset in[0,B-1], with multiplicities retained. Vieta gives the two moment identities. The packed/balanced square-sum bounds apply to the integer offsets; unioning all integer lifts of S0 handles modular aliases. Thus each actual E lies in at least one computed arc. A rejected fixed-S/E-prefix subcube cannot contain a Pplus root. Retaining all S/E literals matters because the implication was conditional on those assignments, including auxiliary fields.

CNF premise: canonical range bootstrap is only an overapproximation. Root implies Cplus; Cplus need not imply any source norm or moment equation. Therefore admitting the clause from Cplus alone is unsound. Custom lemma verification supplies a theory-valid implication Pplus=>L. A complete valid model supplies existential evidence for its original projection, so blocking that whole projection is legitimate bookkeeping, not a logical consequence of Pplus.

Coverage: assume an unrecorded original projected root. Extend it canonically to Pplus; it satisfies Cplus and every L by soundness. Since its projection is unrecorded it satisfies every Bmod. It is therefore a satisfying assignment to R, contradicting the independently verified UNSAT proof. The proof needs neither arithmetic completeness of Cplus nor unique auxiliary witnesses. RAT steps inside final refutation are handled by the proof checker; RAT-only clauses cannot be reclassified as semantic L because they may discard models.

Costs: hM<hp bounds first-moment lifts by h; integer interval residues give at most2h arcs. Intersection tests use signed floor/ceil and do not enumerate values.
