For support coefficients u=u_(h−1), j=u_(h−2), append S+u+ht=0 and E−j−(h−1)tu−binom(h,2)t²=0. Retain all original rows and projected coefficients. For ell=ceil(log2 p) and g=popcount(p−1)−1, canonical compilation adds 2ell value bits and 2g range-state bits. Authenticate the entire chart and new named layout: old state positions may shift. A p17-only control has g=0 and cannot expose that shift.

After fixing all S bits, the conditional integer extrema produce at most h sum lifts and 2h canonical E arcs. An arc [L,U] intersects E low-bit prefix r of depth d exactly when ceil((L−r)/2^d) ≤ floor((U−r)/2^d), using signed mathematical floor and ceiling. Reject only if every arc misses. The clause negates every assigned S bit and E prefix bit; retain auxiliary literals. At p17,h3,B4,t0,S0=3, E lies in the necessary interval [0,3]. Prefix r4,d3 admits canonical E=4,12, so the eight-literal clause excludes that subcube. This does not assert feasibility of the original S branch or pruning frequency.

The crucial source correction is the distinction between the full Boolean polynomial source Pplus and bootstrap CNF Cplus. Current bootstrap clauses impose only canonical value bounds; they do not encode arithmetic or recurrence-state equations. The moment clause is implied by Pplus, generally not by Cplus. Existing completion checks polynomial identities and prefix coverage. There is no current DRAT invocation on this path. The new interface is prospective, not a detected runtime bug.

For final completeness, independently validate full source models and witnesses, deduplicate original projections, and block all and only original projected value bits.
