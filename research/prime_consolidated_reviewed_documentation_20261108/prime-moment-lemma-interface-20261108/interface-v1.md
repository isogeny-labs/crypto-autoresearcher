# Authenticated moment-lemma interface: public specification for review

SOURCE/DESIGN ONLY. No implementation or execution admission. Let p be externally certified prime>3, h in{3,4,5}, finite target, nonsingular curve and interval t+[0,B-1] modulo p, B=2^s<p. Scope is the exact full interval chart generated by composition.py, with unchanged rationality arm/stratum and original projected coefficient order. The retained six coset cells do not satisfy this interface without separate support transport; old implementation prohibitions and all budgets remain unchanged.

## 1. Distinct objects and concrete conservative extension
F0 is the authenticated original field polynomial chart, including norm, target, interval idempotent/nilpotent, stratum and rationality rows. P0 is its canonical Boolean compilation INCLUDING range-state equations. C0 is the compiler's bootstrap CNF of canonical value upper-bound clauses. C0 is an overapproximation of P0 roots; it is not a full encoding of arithmetic or recurrence-state equations. Current completion is prefix-cover plus polynomial identities, not a final DRAT invocation.

Append exactly two FIELD AUXILIARIES named moment.S and moment.E, never projected, and exactly two linear rows:

    moment.S + support.u(h-1) + h*t = 0,
    moment.E - support.u(h-2) - (h-1)*t*support.u(h-1)
             - binom(h,2)*t² = 0.

All original field rows and projected names remain. Recompile this extended source through the same canonical field-range construction, obtaining Pplus and Cplus. Let ell=ceil(log2 p) and g=popcount(p-1)-1. The new variables add2ell value bits and2g range-state bits. The original state-bit positions may shift: derive the exact old-to-new bit map from matching named block metadata, never assume an identity bit map. Bind source, layouts, polynomial arrays, clauses and map by canonical content hashes. No arbitrary low-degree caller polynomial is accepted as an authenticated chart.

The extension contract to prove is: each P0 root has a canonical Pplus extension satisfying Cplus, every Pplus root restricts to a P0 root through the recorded map, and original projected coefficient values are unchanged. Original and extended range states remain polynomially constrained. A producer may not append unlinked S/E bits and use this theorem.

## 2. Authentication envelope and trust boundary
A fixed versioned schema 'prime-moment-semantic-interface/v1' has ONLY these logical components:

- SourceBinding: exact public chart descriptor(p,curve,target,h,t,s,arm,stratum), primality evidence/reference accepted by an independently specified field verifier, original source/compiler identities and canonical content digests, original field variable names/projection, full original row list or authenticated reconstruction, old compiled polynomial/CNF/layout digests.
- ExtensionBinding: names of u(h-1),u(h-2), the exact two rows above, complete extended source and compiler layout, bit maps, Pplus/Cplus digests, unchanged projection map and signed-witness reconstruction binding.
- Limits: finite parser/variable/row/clause/model/proof-byte/verification-work limits, all fixed by a future admission before execution. Exceeding any cap is a refusal, not partial acceptance.
- Records: semantic lemma records, independently valid model records, optional existing proof families ONLY if their verifier and translated source/bit bindings are explicitly registered, and a final residual-CNF refutation record.

Authentication reconstructs the expected FULL chart from the trusted descriptor and exact allowed source version, compares all rows/layouts/canonical serialization, verifies the two additions and unchanged original content, and confirms prime/curve/stratum premises. Hash equality binds content but is not a proof that arbitrary supplied rows are a chart. The runtime implementation and primality/proof-checker integrations are not supplied by this note; missing accepted dependencies mean the future interface refuses acceptance.

Typed integers exclude booleans; field residues lie0..p-1; masks/literals fit their exact layout; reject duplicate names/indices/fields/clauses where schema forbids them, unknown keys, stale digests, wrong signs, omitted/extra rows, changed projection or unsupported stratum. The current tools assume primality externally; this interface must not falsely report they certified it.

## 3. Semantic lemma record and independently recomputed predicate
A record carries exactly(kind='moment_interval_exclusion', extension_digest, S0, depth, prefix, clause). Require0<=S0<p,0<=depth<=ell,0<=prefix<2^depth. The record fixes ALL ell bits of moment.S and depth low bits of moment.E. It does not fix other fields. The verifier derives bit IDs from the authenticated layout and reconstructs the clause as the negation of those assignments: a1-assignment contributes negative literal and a0-assignment positive literal. Sort by absolute variable ID, reject duplicates/opposite pairs or any literal/content mismatch. Do not drop auxiliary literals or reinterpret it as a projected-only clause or contiguous global prefix.

Put M=B-1. Compute every integer lift S=S0+lp in[0,hM]. There are at most h. For M=0 only S=0,E=0 is allowed. Otherwise for each lift let c=floor(S/M),r=S-cM,d=floor(S/h),r0=S-hd. Independently compute

    Qmax=cM²+r²; Qmin=(h-r0)d²+r0(d+1)²;
    Emin=(S²-Qmax)/2; Emax=(S²-Qmin)/2.

For S=hM use c=h,r=0. Map each entire integer interval[Emin,Emax] to its canonical residue arc(s): if Emax-Emin>=p-1 it is all[0,p-1]; otherwise one arc or two wrapping arcs. These are necessary supersets, not exact feasible moments. No lifts gives no arcs. At most2h arcs suffice without merging.

Let H=2^depth and rprefix=prefix. An arc[L,U] intersects the prefix exactly when

    ceil((L-rprefix)/H) <= floor((U-rprefix)/H).

Use mathematical signed ceiling/floor, not truncation toward zero. Admit the semantic clause ONLY when all arcs miss. At depth0 any nonempty arc intersects. At depthell a prefix>=p has no canonical completion. A full-field arc forbids rejection of every canonical-completable prefix. A producer-supplied arc table, success boolean or cached result is never authority; endpoints are recomputed or fetched from a validated exact-key cache.

The claim to prove is Pplus implies each admitted clause. It is NOT Cplus implies that clause. For p17,h3,B4,t0,S0=3, bounds are[0,3]; depth3,prefix4 has canonical E completions4,12, neither inside. Its clause has5 S literals and3 E literals; all unrelated coefficient bits remain unassigned. This is a hand control of the predicate, not a claim the original S branch has a valid relation or that rejection is frequent. Range-only bootstrap admits these canonical S/E values, illustrating why it is not the lemma's premise.

## 4. Model records and exact projected blocks
Each model record supplies a complete assignment for Pplus, its original projected coefficient tuple and original EC/chart witness. Verify every polynomial/range equation and Cplus clause, recover the mapped P0 assignment, check the unchanged original source/model and original signed/witness obligations, and compare projection exactly. Deduplicate by original projected tuple; do not count auxiliary S/E or range states as separate models.

For an accepted model, construct its block over ALL AND ONLY the original projected value bits, forbidding that projection and every auxiliary witness for it. Such a block is intentionally not implied by Pplus; it means that this already checked existential projection has been recorded. Do not accept a block for an invalid/unverified model, omit projected bits, or use only one auxiliary witness's full-assignment block when claiming that projection was fully enumerated.

## 5. Final coverage: a proposed new residual-CNF proof interface
Let L be all individually accepted semantic/proof clauses, and Bmod all reconstructed projected-model blocks. Form the EXACT initial residual CNF

    R = Cplus AND L AND Bmod.

Serialize it canonically, bind variable numbering/clause order/multiplicity and digest, and verify a final UNSAT proof against THAT initial CNF using a registered independently checked proof format/checker version with bounded resources. This is PROPOSED machinery, absent from the current prefix-only path. No empty-clause assertion, solver exit code or trace from another initial CNF substitutes for proof acceptance. Empty model list is allowed only if this same process proves no projected root exists. On missing/incomplete/rejected proof, only independently validated partial model/lemma results may be retained; completeness is false/censored.

The coverage claim to prove is: since every original root extends to a Pplus root satisfying Cplus and all admitted L, UNSAT of R means every valid original projected model equals a recorded model. Cplus need not encode all arithmetic. Conversely this proof says nothing about whether search discovers enough clauses to finish within a budget.

RAT/RUP steps INSIDE the final UNSAT proof may use their proper satisfiability-preserving proof rules. They are not automatically Pplus-valid semantic pruning clauses and may not be admitted to L or used to alter the official projected model set merely because they are RAT. Example control: from an empty CNF, adding a unit(x) is vacuously RAT and loses the x=0 model. This does not make a correctly checked final refutation unsound; it shows why internal refutation transformations and externally admitted model-preserving lemmas have different roles. Any preprocessing used for model enumeration needs explicit model reconstruction/equivalence guarantees beyond a RAT label.

## 6. Costs, cache and malformed controls
Per lemma: at most h lifts and2h arcs; O(h) integer operations on O(log p)-bit operands for fixed h<=5, plus O(ell) clause/input work. Charge exact arithmetic bit complexity, parsing, source reconstruction/hash checks, extension compilation,2 added field blocks and states, all polynomial/model/witness checks, cached bytes/lookups, final CNF construction, proof generation and independent proof checking. No whole-task O(h) claim, pruning-frequency estimate or regularity improvement follows.

Cache only successfully authenticated immutable source/extension objects and recomputed arc unions. Arc key includes theorem/schema version, full extension digest, p,h,t,B and S0; clause results additionally include depth,prefix and layout identity. Include explicit byte/cost caps and eviction accounting. A failed/malformed/partially verified record never populates a success cache. Source/theorem/layout changes invalidate the relevant keys; no cross-target/source reuse based on matching numeric S alone.

Required source-static controls: unlinked/wrong-sign moment definitions; swapped u/j; omitted original constraints; changed interval/coset descriptor; changed primality/field; shifted-bit stale clause; missing S literal; auxiliary literal dropped; omitted lift or wrapping arc; wrong signed division; empty/fullfield/d0/dell cases; interval hole passed as actual support; duplicate/invalid model and wrong projected block; RAT unit admitted as a semantic clause; final UNSAT proof bound to missing clauses/different CNF. State the expected refusal/rejection distinction for each in implementation admission.
