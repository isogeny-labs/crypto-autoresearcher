# Certified partial-prefix SAT search

This additive implementation compares complete-model checks with true partial-assignment checks in the same PySAT CaDiCaL195 external propagator. It preserves the frozen quartic, membership, quadratic and reversed-quadratic encodings. No scalar-recovery algorithm, regularity result or performance advantage is asserted by the implementation.

The only strategy gate enables polynomial work while `assigned_count < n`. Eligible depths are the declared contiguous LSB prefixes; a proof records both assigned count and contiguous depth. Work after all variables are assigned cannot count as partial pruning. Both strategies use a full, nonlazy propagator, lowest-unassigned negative decisions, seed zero, the same PC bounds/cache, and the same external-clause delivery. Checked projected model blocks are queued outside each solve and delivered through the callback on the next solve. Fixed assignments survive backtracking.

Every arithmetic rejection includes an independently checked multiplier identity. Bounded polynomial UNKNOWN causes no clause. Exhausting the PC-call allowance disables further PC attempts but retains a checked full-restriction inverse certificate for invalid complete assignments. The pending-clause queue distinguishes an actual empty clause from no clause. Search completion is checked through the accepted sparse-prefix adapter, without an exhaustive Boolean-cube census. Each projected model has one full witness; other auxiliary witnesses are outside projected enumeration.

`driver.py --config PATH --output DIR` requires native launch/environment receipts. Each deterministic arm slot gets final and partial transcripts, a row, and stdout/stderr logs. A process watchdog preserves partial proofs and explicitly censors the arm. Native decision/conflict limits and outer-call limits also censor. No automatic retry or scientific resume is implemented. References run after all search/control arms. `driver.py --verify RAW` checks the complete inventory, exact input selection, transcript identities/coverage, projected sets against complementary-point certificates, A/A equality and counter consistency.

Phase accounting separates construction, restriction/PC/evaluation events, inverse calls, online proof checks, native SAT counters, offline verification, reconstruction and reference work. The historical ring does not count every machine operation; its retained arithmetic counters are not total runtime cost. Reference instrumentation counts actual source function and builtin `pow` calls, not field-operation totals. Wall/process time and RSS are descriptive. A watchdog can leave only partial counters; those are unavailable for a complete-work comparison. Missing and zero arithmetic entries are normalized only for the explicitly additive Counter reconciliation; no census is used.

The prospective curve experiment is a separate admission. The software suite runs only the four declared F5 synthetic families, callback-state checks, supplied censored transcripts and malformed-certificate controls. `software-integrity.json` retains every invocation, exact source, hashes and subprocess output, including failures. It authorizes no p17/p97 curve execution.
