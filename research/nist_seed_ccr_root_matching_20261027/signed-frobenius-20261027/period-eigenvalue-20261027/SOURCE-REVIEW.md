## Why the CM check does not confuse conductor with CM field

For the certified prime-field inputs, put t=p+1-n and Delta_pi=t^2-4p. An ordinary isogeny class containing j=0 has CM field Q(sqrt(-3)), so -Delta_pi=3*v^2 for an integer v. A class containing j=1728 has field Q(i), so -Delta_pi=4*v^2. These are square-class identities, not a test for divisibility by three or a test that an endomorphism-order conductor equals three. No complete factorization or exact conductor computation is needed, including for P-384.

The independent norm calculation follows algorithm 9.5's unit-multiple idea. Represent p=a^2+3b^2 or p=a^2+b^2, then enumerate the six or four possible traces. This tests the isogeny class rather than just asking whether the supplied model has j=0 or 1728. The positive controls deliberately have generic j-invariants.

For the cohort, the certified full group order n is prime. Any nonzero point therefore has order n. Each special-CM candidate order lies in the Hasse interval, whose width is 4sqrt(p), smaller than n here. Consequently a different candidate order cannot annihilate such a point. Thus, conditional on the existing certified p,n and a valid affine point, the negative route flags also preclude accidental acceptance of one of these wrong special orders in algorithm 9.5. This is a group-theoretic derivation from the certified inputs, not a new execution of its randomized point generator.

It does not exclude other CM fields, general endomorphism criteria, transfers over extensions or a different caller.
