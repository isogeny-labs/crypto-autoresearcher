## Definition-only invariant and the rejected-collision boundary

Freeze the first test to accept16 distinct sign classes outside the old norm
base and keep exactly **one** definition per accepted auxiliary. Retain all
candidate/rejection traces and costs, but **do not harvest rejected-collision
equations or feed them into producer knowledge**. This matches the unknown
pool domain and avoids giving the candidate information that norm's already
paid pair table could have exposed. Any separate collision-harvesting programme
would need symmetric extraction and costs in the reference too.

For accepted A with stored signed old-native vector d, retain the native
homogeneous row

    z_A - d^T z_old = 0.

Keep those rows in own K with distinct `formal_definition` provenance; they are
neither numeric supplied logs nor collected source/target equations. Under the
explicit one-definition/one-distinct-auxiliary invariant, this definition-only
block has an identity auxiliary coefficient block and contributes zero old-base
Delta by itself. That is the **conditional** control to check, not an assertion
that all own K must always have zero gain.

A pair sum hitting an old atom, or two different old coefficient vectors hitting
the same signed point, can otherwise produce an old-base relation without any
numeric public log. Rejected examples must remain auditable even though this
first test does not use them. Later legitimate **own public constructor/source
coincidences** can also make total K informative and must remain attributed.
Do not silently classify every structural K equation as numeric supplied
knowledge or force a known point to remain an unknown.

Formal coefficient vectors are not scalar labels. Never insert A into a
numeric P-multiple cache as if d^T z_old were known. Target P/Q scalar
constructors may use only the arm's actual paid numeric knowledge; fixed formal
points belong in geometry/query lookup and native equations. Cross-target and
base/point Registry equalities remain explicit with original provenance.

## Exact row semantics and information tests

Implement a distinct auxiliary-role API rather than reusing requested target
indices. Preserve the original projected norm coordinates; append auxiliary
slots separately from the eight requested target coordinates. Native norm32+
aux16 and target8 fit native48/joint64. Keep pair8192/rows4096/labels8192/cache64
and all finite candidate gates fixed. No source guard expansion is approved.

Add an independent **signed expanded-old-coefficient oracle**: reconstruct each
accepted formal point from its stored native vector with separate group
arithmetic; check canonical sign and the public point equation. For every
collected row, substitute each formal definition into its old-native vector
without discarding repeated indices, coefficient multiplicities or cancellations.
Check the expanded row's RHS and public group identity, alongside the ordinary
native query/geometry oracle. A triple containing three formal pair atoms can
represent up to six old-atom occurrences. This can be a higher-arity generic
sum dictionary, not a new low-degree or non-generic oracle; the work needed to
construct/query that dictionary must stay visible.

Retain common M as the pure norm-only source stream under common prerequisite
projection, obtained and paid in every own query stream. Formal definitions,
helper units, private constructor anchors and target rows do not enter M.
Separate K_source and K_full; definitions already paid before targets belong
to source K. Source-only accounting never borrows later target constructor
knowledge.

For every source/full and total/own-K view, eliminate **all** auxiliary and
actual target columns U and score

    Delta = rank([[M,0],[B,U]]) - rank(U) - rank(M).

Report supplied/definitional K contribution, collected increment conditional
on own K, source/full target marginal and direct/cross-row contributions.
Require complete cancellation kernel dimensions, sparse original-native
weights, independently dense ranks, old-kernel action and signed public
identities. More retained rows, auxiliary pivots or raw augmented rank are
not information about the original norm base. Given definition rows, direct
symbolic substitution and auxiliary cancellation must agree as a semantic
control; neither is assumed cheaper before actual counters exist.

Test all eight independently chosen requested target **unit functionals** in
the complete native system, with positive native/public certificates and
negative residuals checked by an independently executed full native joint
control. Do not require full old-base rank or treat rank alone as recovery.
Retain named gained/lost/equal target sets against every reference; increased
Delta need not preserve every target. Never use a checker scalar to construct
a target or reveal a formal/unknown pool log.
