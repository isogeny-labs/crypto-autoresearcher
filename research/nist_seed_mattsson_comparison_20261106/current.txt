SOURCE AND METHOD
------------------------------------------------------------------------------
Seed streams: Anthropic, 'Claude reveals ECDSA curve origins' (2026-10-16),
  https://www.anthropic.com/research/ecdsa-curve-origins
  srand48(unix_time); each candidate = 20 bytes, byte_i = lrand48() >> 23.
Curve from seed: FIPS 186-2 / X9.62 'verifiably random' procedure:
  L = bitlen(p), v = floor((L-1)/160), w = L - 160v - 1,
  c = (SHA1(seed) mod 2^w) || SHA1(seed+1) || ... ; require -27/c a square,
  b^2 * c = -27 (mod p), a = -3, E: y^2 = x^3 - 3x + b.
Square-root convention: for p = 3 mod 4 the root b that is itself a square
  mod p (this matches every published curve); for p = 1 mod 4 (P-224) the
  two roots give isomorphic curves, so the choice does not matter.
Point counting: PARI/GP 2.17 SEA (ellsea / ellcard).
Eligibility filter ('chosen the same way'): same root convention as above
  AND #E = n prime with bitlen(n) = bitlen(p). With this filter the skip
  counts equal the article's: P-256 1, P-224 3, ANSI X9.62 runs 7.
Runs fully scanned: up to the last published candidate of each run.
Not covered: P-384 run (scanned to 1796, no eligible skip; hits 1497 and
  1626 have 385-bit order) and P-521 run (not scanned).

Field definitions in the property sections:
  t            trace, n = p + 1 - t
  twist order  p + 1 + t, factored (small primes < 2^26 shown)
  n-1, n+1     factored the same way; 'smooth part' = product of small primes
  emb degree   smallest k <= 100 with p^k = 1 mod n (MOV/Frey-Ruck)
  CM disc D    t^2 - 4p; 'square part' = largest square of a prime < 2000
  SEA lmax     largest Elkies prime needed if only Elkies primes are used
               (product > 2^(L/2+2)); Atkin/Elkies status of l < 300
