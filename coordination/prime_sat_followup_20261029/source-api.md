# Prospective PNEXT implementation and artifact contract

This contract is prospective. No scientific fixture is authorized until the exact source, config, protocol and native admission are frozen and published. Integrity tests exercise implementation primitives, not the scientific fixture inventory.

The native driver accepts `--config PATH --output DIR` and `--verify RAW_PATH`. It starts with `raw-result.json` and a schema-valid `manifest.yaml` before the first scientific cell, then writes `encoding.json`, `coefficients.json`, `encoding-cells.jsonl` and `coefficient-cells.jsonl`. Initial manifest status is `running`, certificate kind `none`, with launch provenance copied faithfully; the raw summary already exists, so raw_result_pending is unnecessary. Progressive package summaries and append/fsync cell callbacks preserve failures and completed cells. Native supervisor owns command, launch, environment and terminal execution receipts.

`encoding.run(config, checkpoint=None)` and `coefficients.run(config, checkpoint=None)` return dictionaries with `config`, `cells`, `controls`. `checkpoint` is a callback accepting one completed cell record. Each producer retains cell IDs, exact public inputs, all declared arms and all attempted work/censoring. `encoding.verify(payload)` and `check_coefficients.verify(payload)` return `{valid, counts}` and reject missing, duplicated or changed inventory, invalid learned certificates, model-set differences and A/A violations. Checkers must not read reference solutions to generate search clauses.

The raw summary binds exact config bytes by `config_sha256`; it uses `packages.encoding` and `packages.coefficients`, each with `status`, `artifact`, `sha256`, `bytes` once complete. Every package contains its own copied config. The native checker emits one final JSON object `{valid, packages: {encoding: ..., coefficients: ...}}`; the two package reports contain `valid`. The umbrella checker confirms full planned inventory and exact artifact hashes, including the linewise checkpoint files. Search censoring is a valid scientific observation; missing coverage or unsound certificates is an invalid result.

Encoding cells contain `id`, `input`, `reference_models`, and `arms`. The four arms are `quartic`, `membership`, `quadratic`, `quadratic_aa`. Each arm has `search.status` (`complete` or `censored`), `search.models`, `search.costs`, `construction_cost`, `verification_cost`, `reconstruction_cost` and `census.costs`. Complete independent projected-model census checks the encodings even when the bounded search is censored. Encoding equivalence, search completion, certificate validity and counted cost are separate fields and conclusions.

Coefficient cells use `leaf_sat`, `prefix_univariate_gcd`, `exhaustive_reference`, `aa_reverse_prefix`. They retain the coefficient predicate's model set separately from actual recovered relations and chart fallback. A branch pruning certificate must be checked before its guarded clause enters search. All canonical field values, invalid bit encodings, rejected prefixes, root recovery and squarefree exceptional-chart processing remain accounted for. No reference model set may steer candidate order, selected prefixes or clause generation.

Counters identify their phase: construction, search, certificate checking, witness/root recovery, chart fallback, and independent oracle/checker work. Preserve primitive counts and SAT solver statistics, including failed attempts, rather than claim an unspecified universal operation total. The export sums only declared integer counters; different operation types are not silently treated as equal-cost. No timing, intrinsic regularity or attack claim is made. Repeated divisors are outside this squarefree relation claim.

The reference solver must be independent of the candidate encoder for projected-domain completeness and group identities. Corrupted certificate, positive and negative instrument controls must exercise their intended checking paths. Reverse-order A/A controls alter only the declared nuisance order, with semantic equality required; count changes remain observations rather than automatic failures.

The final coefficient fixtures fix curve `(p,a,b)=(17,2,2)` and coset constant `c=1`, degrees 8 and 16, and the first three affine x representatives with least nonzero y. They do not dynamically reselect curves or cosets. Four coefficients are ordered `a2,a1,b1,b0`, with the first three fixed in a prefix. Every cell accounts for all 83,521 field assignments and all 4,913 prefixes in its corresponding complete arm; defensive caps are not UNSAT evidence. The declared relation domain is squarefree point-x subsets. Fallback searches excluded target-x charts and must restore the independently enumerated squarefree point-relation set; repeated divisors are outside this claim.

`checkpoint.policy: none` means no scientific resume. Fsynced cell journals retain partial observations; a failed run needs separate additive admission before any new execution. The common degree-two polynomial-calculus window may discard an unrestricted quartic until a branch restriction lowers its degree; this finite-window comparison does not determine regularity. Export preserves each integer primitive/event field; max/peak fields aggregate by maximum, other counts by sum, with missing telemetry left absent.
