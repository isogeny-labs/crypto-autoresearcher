Keep backend/options, negative preferred phases, lowest unassigned observed variable decision callback, encoding, projection blocking, prefix schedule, unknown-prefix cache policy, proof routine and limits identical. Eligible prefix depths are sorted unique `{0,s,2*s,n}` for EC cells. On an early callback, inspect only eligible depths strictly below n that fit the contiguous assigned prefix. Ignore other assigned variables. The same depth-ascending schedule is used at complete-model checks. A certificate is checked independently before emitting the exact LSB-prefix exclusion clause. Preserve original certificate generators/order; serialized masks must satisfy the accepted adapter. Prefix proofs and complete-model projection blocks use the same delivery path in both strategies. No arbitrary-literal clauses or trusted oracle cuts.

Track assignment level and fixedness. Never undo a fixed assignment. Undo nonfixed assignments only above the requested backtrack level. Discard a queued conflict only if its delivery invariant requires it; all recorded learned identities stay valid globally. `check_model(False)` requires an actual queued rejecting clause. Implement `has_clause` explicitly so a real empty clause is distinct from no clause. Do not use lazy mode as the baseline. Do not claim that solver-native clause simplification preserves the original transcript syntax: retain the original justified prefix clause in the proof transcript.

Every complete assignment is evaluated exactly. An invalid assignment can always be rejected with the full-restriction constant-inverse certificate from one nonzero residual; charge restriction, inverse, certificate construction and check. A valid arithmetic model is returned; the outer loop queues its projected prefix block, and the next solve_limited obtains it through has_clause/add_clause in every strategy. After initial domain setup, use no ordinary solver.add_clause path. Thus both justified prefix conflicts and model projection blocks use external callback delivery; changing that path requires prospective documentation before scientific data. Block only after model verification; one valid witness covers its projection for projected-model enumeration, not all auxiliary roots. Preserve all complete/censored statuses and all partial records.
