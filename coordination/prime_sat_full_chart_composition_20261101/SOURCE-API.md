# Complete-chart composition API

Prospective source specification, 2026-11-01. No execution or outcome is asserted. This completes the API boundary for the existing 22-obligation fixed contract; the affine arm stays separate.

`canonical_chart(descriptor)` accepts exactly p,a,b,k,target,t,s,arm,stratum. Target is null or a canonical two-integer affine point. Booleans do not satisfy integer fields. p>3 prime is a declared caller premise; curve nonsingularity, target membership, 0<=k<=5 and 2^s<p are checked. Arm and stratum are explicit enumerations from the frozen contract. No witness, polynomial IR, variable list or projected-bit list is an input.

The returned field circuit has projected inputs in increasing pole-basis order, with the highest pole coefficient fixed to one. Use names chart.Ai and chart.Bi, keep all lower basis coefficients even when a supplied witness is zero, and give monic U auxiliary names support.ui. Source equations are deterministic sparse polynomials with canonical field coefficients and sorted variable-name monomials. Distinct blocks receive injective prefixes interval., rationality., and stratum.; shared coefficients are substituted explicitly. Export a label-to-block map, complete variable order, descriptor and canonical source digest. A zero equation retains its nonempty label and empty term list.

Special charts are explicit. k=0,target=null,zero stratum gives one empty projected assignment; other strata emit a literal constant obstruction. k=0,finite target and k=1,identity target also emit a literal obstruction. No possible chart is selected using witness data. Impossible cases still produce a canonical source and a literal certificate obligation.

`compile_chart(descriptor)` internally calls canonical_chart, assigns consecutive value bits to projected coefficients first and then auxiliaries, and places all recurrence-state bits last. It calls the corrected compiler's substitute_equations and compile_range using the internally derived generic descriptor. The output binds the whole chart descriptor, source, layout, arithmetic labels and compiler document. Supplying a generic range descriptor does not authenticate chart semantics.

`authenticate_chart(document, trusted_descriptor)` rebuilds the complete expected document, compares its typed canonical content and returns phase receipts. No submitted source or submitted source hash is trusted. A malformed late row rejects even when an earlier obstruction makes the chart unsatisfiable. Any repeated canonical build is counted. No authenticated cache or mutable trust token is introduced in this version.

`construct_assignment(descriptor, checked_chart, recovered_points, optional_beta)` is a witness-only helper. It first checks the original chart and exact signed multiplicities. It fills all fixed coefficient positions, constructs interval idempotents from the known support and nilpotent chain quotient/remainder witnesses, then constructs the declared rationality auxiliaries. It never changes the descriptor's stratum, drops a row or changes the projection. A wrong stratum or failed certificate returns an explicit failure. The source does not depend on helper success. Invalid supplied assignments remain available for residual tests without claiming to be valid witnesses.

For component templates, keep symbolic multiplication and variable registration independent of numerical placeholder assignments. Existing modular_product computes quotient/remainder witness values as well as symbolic equations; a template may use only fixed public dummy inputs with full coefficient slots, and must prove identical symbolic output across the fixed alternative assignments. Existing linear_B_square_block requires a nonzero numerical linear coefficient: its fixed dummy template cannot choose a stratum from the witness. Component input names are mapped to shared symbolic A,B,U coefficients, including structural constants; component intermediates remain auxiliaries. Any substituted coefficient degree above two is a contract failure.

`encode_chart_counted(document, assignment, trusted_descriptor)` and `decode_chart_counted(document, bits, trusted_descriptor)` first authenticate and then use the corrected range encoding/decoding contract. Encoding yields a complete canonical bit assignment, not a satisfiability judgment. Decoding checks exact widths, canonical values and recurrence states before reconstructing the coefficient chart. Root residuals and original signed-chart validity are separate required checks. Receipts distinguish whole-chart authentication, source construction, substitution, range construction, reconstruction, residual checks and signed checking; no phase is relabeled as total cost.

`complete_chart_transcript(document, trusted_descriptor, answer)` authenticates the whole chart before invoking unchanged range completion with its derived range descriptor and exact bootstrap clauses. Retain all original records and censored status. Final full-cube verification uses empty domain CNF and null auxiliary bound. Model decoding or signed-check failure invalidates the output; it does not authorize dropping that projection or adding an unproved clause. No SAT invocation belongs to the fixed software suite.

The subsequent search adapter converts canonical decimal monomial-mask strings to the existing integer-mask Boolean kernel only after authentication, retaining polynomial order and charging conversion. Use engine_bridge.solve, not its coordinate-specific run_cell. Same-coefficient projection across rationality arms is checked separately from the original quartic/membership/quadratic-lift coordinate cohort. A common signed-output map and complete fibers are required before cross-family equivalence is claimed.

The fixed suite covers every fixture and control in fixed-software-contract.json, with independent field and Boolean residuals, altered descriptors/content, both common-root beta signs, and unchanged certificate checks. This stage establishes only fixed software obligations. Complete model-set comparison and pruning measurements require their own frozen execution protocol.

Aggregate residual checker boundary. The existing rationality checker._assignment accepts only nilpotent/guard/slack/constant kinds with fixed component sizes. Do not label a full chart as one of those kinds or weaken that checker. Add check_chart_assignment(document, assignment, trusted_descriptor): authenticate the entire chart from the public descriptor, eagerly validate the complete typed assignment and every polynomial row, then evaluate every aggregate residual with its own explicit sparse parser. Return all residuals and phase receipts; preserve the distinction between invalid arithmetic, malformed input, and signed-chart failure. Independent tests must recompute residuals without importing this evaluator. Reuse the component checker for its declared component regressions, and preserve the original signed-divisor/check_chart and full-cube certificate checkers unchanged.
