Certified SAT integration: concrete remaining interfaces

Status. Source-inspection audit for the existing authorized comparison, not implementation or experiment admission. No target module was imported, no suite/solver/CAS/census was executed, and no mathematical claim was promoted. Source hashes are in source-inputs.json. This audit is outside the fresh k2 reviewer inputs.

Existing solver entry point. engine_bridge.solve already forwards arbitrary ring, polys, domain, projected_bits, limits, strategy and prefix_depths to the certified prefix engine, with per-solve refuter diagnostics. Its run_cell convenience wrapper remains coordinate-specific: engine.run_cell builds legacy encodings, assumes projection width 2*s and verifies through the coordinate adapter. A complete-chart integration should call the generic entry point and the chart-specific transcript checker; changing the convenience wrapper's projection silently would corrupt its coordinate semantics.

Existing full-chart path. composition.compile_chart orders source projection before auxiliaries, allocates canonical-value/range bits and exports the trusted range document. authenticate_chart rebuilds the original canonical chart and compares exact content. decode_chart_counted authenticates, decodes, checks every aggregate equation, reconstructs signed data and invokes the independent chart checker. complete_chart_transcript authenticates the certificate transcript, decodes every reported model and retains explicit model failures. These components supply useful interfaces but do not currently accept an auxiliary-sharing or A0-pivot transformation.

Required transformation interface. Keep the original public descriptor as trust root. A prospective transformed document should bind the canonical original source and exact permitted transformation, its original-row certificate, deterministic substituted row list, variable map, projection map and reconstruction. Recompute these expected bytes rather than trusting a supplied rewritten system. The k2 transformation removes projected A0 and reconstructs it from retained q; its reduced projection must be checked as a bijection to original coefficient tuples. The k3 sharing transformation removes only an auxiliary inverse, so its coefficient projection stays unchanged. Keep these distinct. Graded quotient elimination is never a compiler instruction. Retain every nonzero substituted row; any duplicate removal needs its own declared justification.

Polynomial versus Boolean claims. The regularity candidates explicitly augment every field variable with x^p-x. The current chart source export does not emit those rows; its Boolean compiler instead represents canonical values through range constraints. A proof of polynomial solution reconstruction does not automatically prove a bijection of all Boolean auxiliary assignments. A future software suite must reconstruct values and range states, compare complete projected model sets against an independent oracle, preserve full fibers as specified, reject changed domain/CNF/block order, and exercise empty and exceptional charts, both signed outputs and all fixed composition controls.

Confirmed exception-accounting gap. engine.PrefixPropagator._charge snapshots ring.counts, calls function, and only then updates the phase delta. An exception skips that update, even if ring operations already occurred. The later software change needs exception-safe finally accounting with the original exception preserved, meaningful failure-injection checks and no double-charging. This alone is insufficient: engine.solve also bypasses its normal final snapshot and native statistics when a callback or model check raises. Capture attempted-call arithmetic, available native stats, diagnostics and failure status before teardown, retaining the original failure rather than emitting completion. Separate event units from arithmetic/native units.

Failed reconstruction costs. complete_chart_transcript preserves exception type/message per failed model but only appends costs for successfully decoded models. Its explicit failure_cost_boundary assigns interrupted-operation counts to outer workload instrumentation. Such instrumentation is a required comparison component, including failed authentication, range checks, aggregate residuals, reconstruction and certificate checking; a caught exception is not a zero-cost call. Add the work to a durable failed-attempt record even when no valid final transcript can be produced.

Census representation defect to repair separately. encoding.delta emits every key in the before/after union, including zero differences. census reuses its ring's cumulative key set. Therefore a ring previously touched by verification/search can produce extra zero-valued keys compared with a fresh ring, and verify compares the cost dictionaries literally. The previous invalid_output run remains invalid; no output is repaired in place. A later corrected schema should specify the complete metric names and zero semantics, reject unknown metrics, retain raw historical records, and test equality of equivalent counter states without weakening model, witness or budget checks.
