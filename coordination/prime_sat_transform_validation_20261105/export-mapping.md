# Prospective export and report mapping

After actual execution, root/producer emits experiment.export/v1 and validates it with tools/experiment_protocol.py against the published frozen protocol. No result/export is created by preparation.

Use actual protocol freeze hash/version, source commit and dirty readback; local backend; actual runtime/model/session or null when unknown. Bind resource-readback/systemd-state and interpreter hashes. Arms match frozen protocol. Each observed control record maps to its arm, fixed fixture, seed0 and one attempt; absent controls are explicitly incomplete, never fabricated successes. Native censored cases and failed negative controls retain their own statuses. Runtime exceptions map failed, external deadline timeout, infrastructure refusal infra_error; outcome_class not_completed where applicable. resumed=0, checkpoint policy none, no restoration claim.

Counted metrics come only from raw named counters and checked control records. Preserve legacy candidates, callback candidates, native calls, reconstruction and certificate work separately. Missing counters stay unknown, not zero. wall_valid=false for scientific comparison; administrative timing can be recorded without a performance claim. All unavailable host/cost/runtime fields are null with reason; no invented zero cost. Keep original106+6 downstream obligations.

files inventory binds actual raw-artifacts.tar, preliminary/final launcher receipts, manifest, stdout/stderr and actual nested receipts by byte size/hash. artifact-manifest is the pre-final collection inventory; launcher-receipt binds it after collection. Final slot terminal receipt supersedes preliminary status if custody persistence fails. Root final archive manifest binds both final receipts without a circular hash. Results/worker-error/resource-readback may be absent on early failure and must be listed missing explicitly.

Report Markdown/Typst/SVG/PDF and input manifest explain control coverage, rejection layer reached, failures/censored/unsupported outcomes, actual resource readback and source/runtime binding. Review report/export references sealed producer bundle only after independent findings seal when policy permits.
