# Rationality circuit software contract

This is an additive implementation of the seven conditional claims reviewed in TASK-20261031-048643, with the F1 correction in DEC-20261031-430815. Prime p>3, nonsingularity, split monic U and complete normalized chart strata remain explicit premises. No scientific execution is authorized here.

## Explicit symbolic representation

Implement circuits.py with a serializable sparse field-polynomial IR. Ordered named input variables include every potentially free coefficient of U, A and B, even when a fixed fixture supplies their numerical values. Curve constants a,b and p are public fixed inputs. Auxiliary variable names and obligation-labelled equations are explicit. Do not substitute fixed fixture coefficients before deriving total equation degree or counts: U-times-quotient terms must retain their symbolic bilinear structure. All coefficients are canonical modulo p. Preserve declared input, auxiliary and projected name sets, strict name uniqueness, field binding and deterministic order.

Implement a monic modular-product builder L*R=P+U*Q with deg L,R,P<k, deg Q<=k-2, including every coefficient equation and quotient variable. Final-zero products omit P variables and impose remainder zero directly. The circuit evaluator independently recomputes all coefficients and degrees; it must reject malformed values anywhere before evaluating, including unused or late fields. This representation is field-level; it makes no claim to implement Boolean carries or canonical bit ranges.

## Rationality blocks and witness construction

Implement rationality.py. nilpotent_square_block(k,p,a,b) makes U's k non-leading coefficients symbolic and introduces C and modular-product intermediates for (C²-f)^k=0 mod U. k=0 is the separate empty block. For k=1 use the dedicated evaluation v=u0², F=-u0*v-a*u0+b, C²=F, with three auxiliaries/equations. For k=2 use f=(X+q)U+(F1*X+F0), retaining q,F1,F0 and their three equations. For k=3 reduce f by f-U; for k>=4 f already has degree below k. Preserve the reviewed addition chains and exact counts 0,3,9,15,21,36 for k=0..5. Never claim splitting from this block.

linear_B_square_block(p,a,b,mode) has symbolic A0..A3,b0,b1. Define b1*z=1, b1*alpha+b0=0, q1=A3*alpha+A2, q2=q1*alpha+A1, c=q2*alpha+A0, v=alpha², F=alpha*v+a*alpha+b. Guard mode retains c*u=1-e, c*e=0, u*e=0, (1-e)*beta=0, beta²=e*F: ten auxiliary variables and twelve equations. Slack mode retains beta²=F+c*u: nine variables and eight equations. No fixture specialization or unchecked branch may erase an obligation. B nonzero constant uses its explicitly checked inverse; B=0 uses nilpotent rationality. Stratum tags are checked against the actual B coefficients.

Construct auxiliary assignments only from supplied, checked charts and known points; never search for an unknown relation. For C interpolate a chosen root value at each distinct support coordinate, choosing the canonical smaller integer root when both signs are supplied. Modular quotient/remainder intermediates and evaluation variables are derived deterministically and exposed. Symbolic witness-fiber counts are not enumerated or presented as measured model counts.

## Serialization and rejection rules

The exported circuit must specify schema version, p, ordered input names, ordered auxiliary names, ordered projection names, obligation-labelled equations and block metadata. Represent each equation as explicit canonical coefficient/monomial terms; monomials refer only to declared variables. The implementation may choose the exact deterministic JSON layout and document it in README, but the checker must reject unknown schema fields, undeclared or duplicate variables, noncanonical coefficients, inconsistent projection or field binding, missing/extra assignment entries, and malformed terms before evaluation. Monomial exponents are nonnegative integers; Boolean values are not accepted as integers. Compute total degree from the actual unspecialized monomials. Any equation carrying no terms represents exactly zero, not an omitted obligation. The export identifies which equations and auxiliaries belong to each block so accounting is reproducible.

Mandatory mutations operate on the fixed exported examples only: change one modular quotient value, one remainder value, one guard variable, one noncanonical late field value, remove an assignment key, add an unknown assignment key, duplicate a variable name, introduce an undeclared monomial variable, change the projection, change p without reconstructing the bound instance, mismatch the B stratum, and swap F1 signed multiplicities. Expected invalid fixtures count as passing only on explicit rejection; exceptions and timeouts are retained as failures unless that exact rejection is the declared assertion. No mutation search or random fuzzing is authorized.

## Block projection versus chart projection

A standalone nilpotent block has U-coefficient inputs and may expose those inputs as its local projection; this is only a rationality predicate, not a chart/SAT model identity. Standalone guard/slack blocks expose their A/B inputs. When attaching any block to a fixed chart, retain an outer binding containing normalized A/B, U, target, k, interval and stratum, and check every field against the supplied chart. The candidate's chart identity is normalized A/B plus its outer chart tags. Never equate the local U projection with the complete signed chart projection. This implementation must document and test that distinction; actual complete SAT export is subsequent work. Projection names are a duplicate-free ordered subset of declared inputs, and the checker compares them to the expected block or chart binding supplied independently by its caller.
