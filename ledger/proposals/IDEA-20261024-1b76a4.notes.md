## 2. Mechanism and derivation

**Object frame.** Representation R1: the integer, Farey (x = u/v) or rank-r GAP/digit
representative of x(P) in F_p, with an archimedean box |u_c| <= p^{omega_c}. Operation set
Sigma: translation by factor-base elements (index calculus, Class I). Oracle: an HG lattice
built from I_t = (S_{m+1}(.; x_R), p)^t. Trichotomy class: partial-action (relation vectors
propagate only under factor-base translation); the membership component is
coordinate-dependent. KN-OPEN-020 class: implicit membership. Representation class R1 of
RQ-ECDLP-623a32; attack stage: relation decomposition.

**Setting.** f in Z[u_1..u_n], f mod p != 0. Weight w(a) = sum_c omega_c a_c (log_p units).
L = I_t cap Z[M] for a finite support M, coordinates scaled by p^{w(a)}; any shift-built
lattice is a sublattice (larger determinant). Asymptotic HG criterion:
(HG) sum_{a in M} w(a) + e(L) < t|M|, where p^{e(L)} = [Z^M : L].

**Lemma A (index count; hypothesis: (p, f) regular in Z[u]).** e(L) >= t|M| - sum_{k=1..t} dim V_k,
V_k = (f^k mod p) cap F_p[M]. Proof: filter L_j = L cap p^j Z^M; L_t = p^t Z^M. L_j/L_{j+1}
injects into {h mod p : p^j h in I_t}. Since (p, f) is a regular sequence, gr_I Z[u] is a
polynomial ring over Z[u]/(p, f) with p* a nonzerodivisor (Matsumura Th. 16.2, recalled), so
(I_t : p^j) = I_{t-j} and the piece lies in V_{t-j}. Hence (HG) implies
sum_a w(a) < sum_k dim V_k.

**Lemma B (leading monomials).** For any monomial order sigma, dim V_k <= N_sigma(k) :=
#{a in M : LM_sigma(f)^k divides u^a}, because F_p[u] is a domain (LM(f^k q) = LM(f)^k LM(q))
and an echelon basis of V_k has distinct leading monomials.

**Averaging (corner lemma).** Hypothesis: for every choice c = (c_1..c_m) of one coordinate
per slot there is an order sigma_c with LM(f) = prod c_i^D (unit coefficient). Draw c with
P(c_i = c) = omega_c / vol_i. A minimum is at most an average, and prod_i x_i <= min_i x_i
on [0,1], so

sum_k dim V_k <= sum_a sum_k prod_i (sum_{c in slot i} pi_c 1[a_c >= kD])
             <= sum_a min_i w_i(a) / (D vol_i) <= sum_a w(a) / (D vol),

since w(a) = sum_i w_i(a) >= vol * min_i (w_i/vol_i). With Lemma A: **HG success implies
D * log_p(total box volume) < 1.**

Quantifier order: forall m >= 2, forall t >= 1, forall finite M, forall shift sets inside
I_t cap Z[M], forall box weights with D * vol >= 1: (HG) fails. The bound is dimension-free
and shift-free, and it does not depend on how a slot's volume is spread over its
coordinates, hence not on the GAP rank r.

**Premise for S_{m+1} (H2).** S_{m+1} = Res_X(S_m(x_1..x_{m-1}, X), S_3(x_m, x_R, X)); with
B(X) = B_2 X^2 + B_1 X + B_0 and B_2 = (x_m - x_R)^2, Res = B_2^{deg A} A(r_1) A(r_2). By
induction the corner of A has coefficient 1 and sits at X^0, and B_2^{2^{m-2}} supplies
x_m^{2^{m-1}} with coefficient 1. The argument is characteristic-free. The corner is
divisible by every monomial of the support, so it is the LM in every order. Substituted
slots: GAP/digits x_i = a_{i0} + sum_j a_{ij} u_{ij} give coefficient prod a_{i c_i}^D != 0,
LM under lex with the chosen coordinates first; Farey x_i = u_i/v_i gives a bihomogeneous
S^h whose u_i^D, v_i^D coefficients are box vertices, nonzero for generic targets.

**Lemma U (p-adic C4; unconditional, single corner).** Hypotheses: f in Z[u] has a monomial
u^{a0} with p not dividing its coefficient, and u^{a0} = LM(f) for some order. Over Z_(p),
G = {p^{t-k} f^k : 0 <= k <= t} is a strong Groebner basis of (p, f)^t (S-polynomials are
multiples of p^{t-k} f^k with standard representations; G-polynomials are basis
elements). So every nonzero g in (p, f)^t with LM(g) = u^a has leading coefficient in
p^{t - kappa(a)} Z, kappa(a) = min(t, max{k : k a0 <= a}). Since w(a) >= kappa(a) w(a0),
||g(Xx)||_inf >= p^{t - kappa + kappa w(a0)} >= p^t whenever w(a0) >= 1. Quantifier order:
forall t, M, shifts: if exists a unit corner of weight >= 1 then forall nonzero g in
(p,f)^t, ||g(Xx)||_inf >= p^t, so no HG-useful polynomial exists (no Gaussian heuristic).
