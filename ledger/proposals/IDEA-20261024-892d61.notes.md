## 2. Mechanism and derivation

**Hypotheses.**
- (A1) G = E(F_p) has prime order r, i.e. #E = r.
- (A2) F is a signed base: B distinct abscissae, the points +-P_i. A useful triple has three distinct point ids from three distinct x-orbits (ORACLE_FORMAT.md). So |U| = M = 8 C(B,3).
- (A3) R is uniform on G minus O. That is the panel's target law (H1).
- Write u(R) = #{T in U : sum T = R}. Set lambda = E u, cov = P(u >= 1) and kappa2 = E[u(u-1)]/lambda^2.

**(I1) Conservation and exact mean.**
- Every triple sum lands in G, so sum over all R in G of u(R) = M (KN-FIND-007 restricted to U). Hence lambda = (M - u_O)/(r-1).
- A useful triple summing to O contains three signed pairs from distinct orbits. Each of the 4 C(B,2) such pairs lies in at most one such triple, since the third point is -(P+Q). So 0 <= u_O <= 4 C(B,2)/3.
- The relative spread of lambda over bases is u_O/M <= 1/(2(B-2)): 0.20% at B = 256 (P29) and 0.03% at B = 1600 (P37).

**(I2) Markov ceiling.** u is integer-valued, so 1{u >= 1} <= u and cov <= lambda.

**(I3) Paley-Zygmund floor** (Cauchy-Schwarz, theta = 0).
- (E u)^2 = (E[u 1{u>=1}])^2 <= E[u^2] cov.
- E[u^2] = E[u(u-1)] + E u = kappa2 lambda^2 + lambda.
- Hence cov >= lambda/(1 + kappa2 lambda). This is the Jensen form of cd7b7e's identity (i) applied to useful triples.

**(I4) Ratio bound.** For two size-B bases F, F' with the same r:
- cov(F)/cov(F') <= (lambda_F/lambda_F')(1 + kappa2(F') lambda_F').
- By (I1), lambda_F/lambda_F' <= 1/(1 - 1/(2(B-2))) = 2(B-2)/(2B-5).
- So a ratio >= 1.2 needs kappa2(F') >= about 0.2/lambda, up to that factor: 0.2/0.0690681 = 2.90 at P29 and 0.2/0.0667695 = 3.00 at P37.
- The ratio bound needs no isogeny at all.

**(I5) kappa2 and coincidences (heuristic H2).**
- (r-1) lambda^2 kappa2 counts ordered pairs of distinct useful triples with the same non-zero sum.
- Under a random-base model kappa2 is about 1 (the Poisson value).
- Each additive coincidence Pa + Pb = Pc + Pd in the base creates about 2(B-4) equal-sum triple pairs {a,b,x}, {c,d,x}, so the excess is about 4(B-4)/((r-1) lambda^2) per coincidence: 0.00066 at P29.
- The coincidence count is O(B^2) to compute (paircoin). This is a 2-energy statistic of the base.

**(I6) Transport.**
- An isogeny of degree prime to r restricts to an isomorphism G -> G' (Tate; KR-RHO-755e35; IDEA-20261015-e0b5dd (A)).
- So u'(phi(R)) = u(R) for every R, and a transported base has identical D.

## 5. Lean targets (proposed, not written)

Proposed file: `formal/CryptoResearch/IC/OccupancyBand.lean`. The statements are over a finite set X with uniform measure and u : X -> N, with lambda = E u > 0 and kappa2 = E[u(u-1)]/lambda^2.

1. **Markov ceiling.** #{x : u x >= 1} <= sum_x u x.
2. **Cauchy-Schwarz floor.** (sum_x u x)^2 <= (sum_x (u x)^2) * #{x : u x >= 1}. Equivalently cov >= lambda/(1 + kappa2 lambda).
3. **Conservation.** For a finite group G of order r and a finite family T with sum map s : T -> G:
   - sum_{g in G} #s^-1(g) = #T;
   - the mean over G minus {0} is (#T - #s^-1(0))/(r - 1).
4. **u_O bound** (abstract form). In an abelian group, let S be a finite set of signed elements and let the triples summing to 0 use pairwise-distinct orbits. Then their number is at most (number of admissible pairs)/3, because each pair determines the third element.
5. **Ratio bound with the lambda factor kept.** Hypotheses: cov <= lambda, cov' >= lambda'/(1 + kappa2' lambda'), and u_O, u_O' in [0, M/(2(B-2))]. Conclusion: cov/cov' <= (2(B-2)/(2B-5)) (1 + kappa2' lambda'). Dropping the factor makes the statement false by up to 1/(2(B-2)).
6. **Transport.** For a group isomorphism phi : G -> G' and F' = phi(F), u_{F'}(phi R) = u_F(R) for all R.
7. **Non-vacuity.** The P29 constants (r = 320091991, B = 256, lambda = 0.0690681) satisfy every hypothesis.
